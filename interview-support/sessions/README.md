# セッション記録

新システムの演習・支援セッションはまだない。実施後にYYYY-MM-DD-NN-topic.mdで保存する。

## 記録項目

- セッションID、日付、mode: case/fermi、目的、出典URL・利用可能な資料への参照。
- 使用した手順・知識の版（コミット等）、問題の公開可能な要約、時間・制約。
- 問題で与えられた条件、確認済みの事実、置いた仮定を分離。
- 本人の考え、Codexの提案と回答、数値・単位・計算、途中の訂正と理由、結論。
- 回答例との比較、本人のフィードバック・共同検討、評価できた点と未評価点。
- 未解決点、次の行動、関連する学習記録へのリンク。

ケース内の推定はmode: caseの同じセッションに推定部分として記録し、単独フェルミの実施と誤計上しない。複数チャットへ引き継いだときは継続元・前提を結ぶ。

観測・実際の発言と後からの解釈を区別する。未計測の速度・精度・改善を作らない。非公開問題・解説・私的な情報を公開GitHubへ全文複製しない。

## ①②の保存範囲

①の教材演習は各solve/learningが正本で、ここに全文複製しない。ここは②・本番・準備確認の対話記録。mode、layer/purpose、①②の参照版を記し、各support/learningの評価からリンクする。
