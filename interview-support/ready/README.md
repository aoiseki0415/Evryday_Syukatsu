## 読み込むもの

1. SPEC・OPERATIONS・対象モードPLAYBOOKで目的、①②、適用範囲、現在の準備状態を確認。
2. 対象solveのCURRENT→CORE→INDEXから必要な詳細の解法・知識を読み、回答全体を導く基盤を復元。
3. 対象supportのCURRENT→CORE→INDEXから必要な提示・途中依頼の詳細ルールを読み、本人への支援方法を復元。
4. 共通の概数・施策・知識、必要時の探索経路、直近の失効・訂正を確認。
5. 使用版、読み込み済みの項目、不足・未評価範囲を記録する。必要な情報を読み終えてから準備状態を表示する。
