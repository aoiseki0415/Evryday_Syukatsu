## 読み込むもの

1. SPEC・OPERATIONS・対象モードPLAYBOOKで目的、①②、適用範囲、現在の準備状態を確認。
2. 対象solveのCURRENT→CORE→INDEXから必要な詳細の解法・知識を読み、回答全体を導く基盤を復元。
3. 対象supportのCURRENT→CORE→INDEXから現行の支援ルールを読む。フェルミは準備と初回共有を分け、初回後の質問対応は未策定として扱う。
4. 対象に必要な共通概数/定義、必要時の探索経路、直近の失効・訂正を確認。単独フェルミにケース固有の施策本文を必須にしない。
5. 使用版、読み込み済みの項目、不足・未評価範囲を記録する。必要な情報を読み終えてから準備状態を表示する。

CURRENTは現行文書への案内であり、リンクだけ見て内容を読んだことにしない。過去の全演習ログを毎回読む代わりに、採用済み情報を整理したセットから必要な本文へたどる。将来要約を作る場合も正本と版・更新日を結び、別々に古くしない。

お題受領後は、回答全体を構築・確認した上で、初手として必要な部分だけを短く提示する。①の解く範囲を初手に限定しない。ケースの途中依頼は既存方針を維持し、フェルミの初回後の具体的対応は今回定義しない。

優先度が低いことは準備時に不要という意味ではない。優先度で読む順と要約範囲を調整し、回答全体を解く基盤を削らない。
