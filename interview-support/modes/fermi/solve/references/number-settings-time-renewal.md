# 頻度・更新・流量の橋渡しの設定例

更新/本文照合2026-11-26。FERMI-REF-C-001の内訳、C参照用v1。[性質O/T/D/Gと使い方](NUMBER_INDEX.md)。平均保有期間、実効購入率、当年の交換日、瞬間在庫と期間flowは異なる。閉じた与件がある場合は下の自由仮定を上書きしない。

<a id="fnum-040"></a>
## FNUM-040｜PC：保有から個人利用・置換・新品へ

- **出典/日付/性質**：[CM-F-010](../learning/2026-11-26-05-casematch-pc.md)、2026-11-26。Dの二人以上世帯の保有値/調査範囲/旧品年数は[FACT003正本](../details/rough-anchors.md)へ。Oは二人以上/単身60/40%、単身全世帯平均.7台、元保有の90%を対象個人利用stock、**実効的な置換購入年率1/6**×新品選択80%。非保有世帯の年2%が1台初導入×新品80%、既存保有の年1%が追加新品1台。
- **設定理由と比較**：機能/OS/故障/用途変化で数年ごとの置換、新品/中古の選択、少数の初導入/買増しという行動模型。1/6は観測寿命ではない。AIは計算を支持したが、90%補正後の利用PCを持つ主体と追加の主体数hが一致する条件不足を指摘。事後補足hは新しい観測でない。
- **移植条件**：置換/初導入/追加の同じ購入を二重計上しない。期首の元中古PCを利用stockから落とさず、旧品の国内移転/保管/廃棄と新品購入を区別する。D旧品平均7.7年は買替え世帯だけの選択付き観測で、年購入率を自動1/7.7にしない。方法：[NS-01](../details/number-setting-methods.md#ns-01)、[NS-03](../details/number-setting-methods.md#ns-03)、[NS-05](../details/number-setting-methods.md#ns-05)。

<a id="fnum-041"></a>
## FNUM-041｜自転車タイヤ：距離・経年・退出世代

- **出典/日付/性質**：[CM-F-005](../learning/2026-11-25-11-stock-transfer.md)、2026-11-25、O。高/中/低利用20/60/20%、年距離は10km×250日＝2500km、3km×180＝540、2km×80＝160。後輪4000km/前輪6000km又は経年5年の早い方で新品交換。車体が対象日常利用から最終退出するまで子供用4年/15歳以上用8年、世代均等/導入退出安定を仮定。
- **設定理由と比較**：通勤通学/買物/週1〜2回という像、後輪の荷重/駆動、子供用の短い継続という仮説。AIは同式の年約1200万本を再計算しただけで、実寿命/安全推奨/交換実施行動を測っていない。
- **移植条件**：メーカー推奨や保証寿命として使わない。OEM除外/退出時交換除外は原案の条件。中古で車体が使われ続ける場合や同期世代では単純stock/周期が外れる。[CM-F-006](../learning/2026-11-25-12-cohort-transfer.md)は全係数Gの特定年計算であり、この自由率を使わない。方法：[NS-05](../details/number-setting-methods.md#ns-05)、[NS-03](../details/number-setting-methods.md#ns-03)、[NS-CHECK](../details/number-setting-methods.md#ns-check)。

## FNUM-042｜写真プリント：年利用率・回数・枚数

- **出典/日付/性質**：[CM-F-007](../learning/2026-11-25-13-photo-print.md)、2026-11-25、O。年内の高頻度10%/随時30%/利用なし60%の排他的世帯群。高頻度4回/年×50枚/注文、随時1回×30枚。季節の整理/行事/旅行等で選んだ分だけ紙へ出す像。通常利用世帯の10%が年2枚の大判を買う追加もO。
- **比較**：AIは原案の同式計算を支持。事後の[2022年調査の読解](../input/2026-11-25-photo-print-followup.md)は、特定のスマホ撮影者の累積経験を測るもので、この年利用40%や年200/30枚を実証しない。
- **移植条件**：経験/当年有料外注、個人/世帯、自宅印刷/外注、通常/大判だけ利用をそろえる。注文枚数と購入回数へ同じ頻度を重掛けしない。価格/送料構成は[FNUM-018](number-settings-prices.md#fnum-018)。方法：[NS-05](../details/number-setting-methods.md#ns-05)、[NS-03](../details/number-setting-methods.md#ns-03)。

## FNUM-043｜ペット取得：飼育stockから有償加入flow

- **出典/日付/性質**：[GYM-023](../learning/2026-11-26-01-gym-additional.md)、2026-11-26、O。犬猫の導入/最終退出が安定、平均飼育12年、加入の有償50%、取得平均10万円。飼育頭数の規模から加入を作る模型で、寿命・保護/譲渡・購入価格の実測はない。
- **T比較**：平均15年、有償50%、取得30万円。Oと同じ市場約2兆へ丸まっても、取得flow/価格と維持費の組合せが違い、実数精度の証拠でない。
- **移植条件**：stock/寿命が成り立つ定常/境界条件を先に確認。頭数年の維持費へ購入額を毎年全頭分足さず、中古/保護譲渡を新品販売同様に扱わない。方法：[NS-05](../details/number-setting-methods.md#ns-05)、[NS-07](../details/number-setting-methods.md#ns-07)。

<a id="fnum-044"></a>
## FNUM-044｜倉庫：同時容量から平均出荷率

- **出典/日付/性質**：[CM-F-009](../learning/2026-11-26-03-casematch-warehouse.md)、2026-11-26、混合G/O。面積/通路/箱底面/最大段数/年稼働日からの同時容量38400箱はG。Oは**箱の収容能力に対する期間平均在庫75%**と、同じ対象の正常出荷箱の**平均10稼働日**保管。入出荷/品目の余裕を残し、約2労働週で入替える模型。
- **比較**：AIは38400×.75÷10×250＝72万箱/年という同式を再計算し、率/平均の分母の明記を支持。現物の平均在庫/滞在を得たわけではない。
- **移植条件**：75%は面積率でも年末1日の率でもない。10は暦日でない。定常/端点、対象箱の一致、注文/荷捌き/ピークを要する。容量38400は年flowの上限でなく、平均だけでピーク/実行能力を保証しない。方法：[NS-05](../details/number-setting-methods.md#ns-05)、[NS-CHECK](../details/number-setting-methods.md#ns-check)。
