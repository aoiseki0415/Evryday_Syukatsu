# フェルミ①｜数字設定の参照例

更新：2026-11-26。**FERMI-REF-C-001、C補足、参照用v1**。本文の出典対応を監査した索引であり、個々の係数を現実の最適値・確認済み全国値として採用した知識ではない。

最初に[NUMBER_INDEX](NUMBER_INDEX.md)を読む。ここは人口等の[基礎アンカー](../../../../shared/knowledge/facts/japan-anchors.md)や[分野の公表概数](../details/rough-anchors.md)とは別層。数字の候補を保存し、同じ対象/分母/期間かを確かめて参照する。基本は[数字設定方法](../details/number-setting-methods.md)から導き、索引は照合や導出困難時の条件付き補助に使う。

| 文書 | 探す係数 |
| --- | --- |
| [NUMBER_INDEX](NUMBER_INDEX.md) | 全47行の入口、性質/利用条件、既存アンカーの正本 |
| [利用・所有・行動率](number-settings-rates.md) | 使用率、普及/複数保有、年齢/地域/生活条件、食事、処分 |
| [価格・支出](number-settings-prices.md) | 商品/チャネル別単価、平均会費、追加購入、移動区間、サービス費用 |
| [空間・設備・処理量](number-settings-space-capacity.md) | 配置間隔、面積比、単店/機器能力、実稼働、物量 |

| [今回確認した公開例](number-settings-public-examples.md) | NASA/大学の教育上の設定例、特定店の掲示料金 |
