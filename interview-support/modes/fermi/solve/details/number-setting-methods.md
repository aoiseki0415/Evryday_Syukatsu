# フェルミ①｜各要素の数字を合理的に設定する方法

更新：2026-11-26。**FERMI-SOLVE-A-003、情報版v1、A必須、標準手順として採用済み**。理由：どの型でも、式に置く主要な率・頻度・単価・密度・期間の選び方が回答全体を左右するため。採用するのは以下の条件付き手順であり、過去問の全係数や自由推定の実数精度・応答速度を認定するものではない。

**対象を定義 → 使える根拠と方法を選ぶ → 対象へ橋渡し → ラフな値を置く → 整合性と主要な幅を点検する。** 「最適」は真値を常に当てる保証ではなく、その場で使える情報と時間の中で、説明可能な設定を選ぶことを指す。

## 位置づけと読む順

- [A-001/A-002標準v2](method-selection.md)：問題型・式から全体回答/検算まで。本項目は**各変数へ数字を設定する工程**を具体化する。
- **本項目A-003**：方法選択と基本確認の正本。以下のNS-01〜07は同じ1項目の方法の枝であり、7件の独立した精度実証ではない。
- [ラフな分野概数](rough-anchors.md)と[共通概数](../../../../shared/knowledge/facts/japan-anchors.md)：人口等の基礎的な知識。保存済みでも、対象/分母/年/条件を合わせる。
- [数字設定の参照索引](../references/NUMBER_INDEX.md)：問題別・資料別の設定例。重要な基礎知識と分離し、照合/困った場合の条件付き転用に使う。
- [B-006候補v1](evidence-and-checks.md)：根拠の橋渡し・独立性・幅の詳細と旧採否。本項目はB-006の全枝を一括して採用へ変更せず、過去に候補v1を使用した証拠も保持する。重複する確認は参照で結び、旧係数の根拠を後付けしない。
- 調査比較は[INPUTノート](../input/2026-11-26-06-number-setting-methods.md)、演習からの抽出と採用理由は[再検討記録](../learning/2026-11-26-07-number-methods-retrospective.md)。②の本人向け表示形式は本項目へ混ぜない。

## まず確認するもの

| 確認 | 必須の判断 |
| --- | --- |
| 推定する変数 | 例：全人口の眼鏡使用率か、所有者だけの購入頻度か。人/世帯/台/回/円と期間を付ける |
| 分母と条件 | 全体平均か、利用/所有/購入した人だけの平均か。対象から除く人・製品・時点は何か |
| 根拠の種類 | 与件／確認済み観測の概数／観測からの導出／本人が共有した実経験／資料の設定例／未確認の記憶／自由仮定を分ける |
| 比較可能性 | 年・地域・属性・商品/利用形態・含除・税/割引・数量単位が同じか。違いは橋渡しの仮定として残す |
| 重要度 | 結果への寄与と変動の大きさを見て、主要係数から根拠を厚くする。小項目の細分化で時間を使い切らない |

人口のような出典付きの基数に未観測の利用率を掛けた全体は、確認統計にはならない。「近視/老眼があるので60%」という理由は方向の説明であり、60%の観測証拠ではない。

## 方法を選ぶ

一つの順序へ全問を強制しない。まず**設問の与件を尊重**し、同条件の確認値があれば使う。未知の値は、観察可能な尺度・層別・近い比較対象・行動/物理制約から、少ない追加仮定で導ける経路を選ぶ。適切な導出ができなければ、条件の近い索引例や根拠のある上下の目安から仮置きし、不確かさを残す。理由のない50%を連続して掛けて済ませない。

<a id="ns-01"></a>
### NS-01｜与件・同条件の既知値を使い、丸める

**使う条件：** 数値が問題で指定されている、又は同じ対象の観測値/料金が確認できている。基礎数値だけでなく、対象に合う利用率・単価にも使える。

**手順：** 与件の対象と期間を優先 → 元の確認値と計算用の丸め値を分ける → 桁を保って計算 → 結論は根拠の精度に合わせて通常1〜2有効数字へ。与件が閉じた計算では必要な精度を保ち、最初から粗く丸めて答えを崩さない。

**条件・失敗防止：** 全国アンカーで設問指定の母数を上書きしない。過去年・二人以上世帯・表示価格などの条件が違う値は、そのまま「既知の今回値」へしない。丸めは不確実性を消さない。確認前の想起は「記憶由来/未確認」のまま。

**既存の証拠：** [CM-F-001〜004](../learning/2026-11-25-09-casematch-stock-time-capacity.md)は固定与件を使い、任意の寿命や人口を加えなかった。[GYM-029](../learning/2026-11-26-04-gym-information-transfer.md)では古い世帯値を現在へ外挿し、[CM-F-010の初回答と事後修正](../learning/2026-11-26-05-casematch-pc.md)では二人以上の調査値を全国へ移す際の条件と限界を残した。出典方法：NUM-S01/S07/S10。

<a id="ns-02"></a>
### NS-02｜身近な観察・共有された経験を、尺度/仮説の出発点にする

**使う条件：** 本人が実際の観察や購入経験を共有した、画面/資料に観測可能な尺度がある、又は確認済みの小単位から広い量を組み立てられる。Codex自身の研究室・購入・外食・旅行の実体験は捏造しない。

**手順：** 観察した集団/物/期間/数え方を明記 → その範囲の率や尺度を作る → 全国/別集団との差を列挙 → 必要ならNS-03で対象の構成へ重みを付け直す。個人が買った価格は、その商品/チャネル/時点の1例としてNS-03/04へ渡す。

**研究室の例の扱い：** 「研究室で6割だった」は今回の会話では方法の例であり、本人が実測した事実として保存しない。仮に実際の人数/率が共有された場合でも、年齢・職業・地域・接触しやすさの偏りがあり、全国6割と確定しない。研究室の若年層の値だけから高齢層の値は得られない。属性で重みを補正しても層内の選択偏りが残る。

**尺度への変換：** 身近な間口→柱間隔、移動時間×速度→距離、茶碗×食事回数→量などは説明可能な導出になる。ただし最初の尺度・頻度が実測でない場合は、具体像を用いた仮定と呼ぶ。写真/図の大きさは既知の尺度と遠近/撮影範囲が必要。

**既存の証拠：** [GYM-018の車窓](../learning/2026-11-26-01-gym-additional.md)は道路沿いの偏りがあり、全国森林率の独立観測にならなかった。同記録GYM-019の40mは住宅間口の像で、設置標準の観測ではない。[EVAL-F-004](../learning/2026-11-25-10-unseen-v2.md)の茶碗量も仮定を明示した。NS-02を代表性の確認済み手法として実証したわけではない。出典方法：NUM-S01/S02/S04/S05/S09。

<a id="ns-03"></a>
### NS-03｜意味のある層に分け、正しい重みで平均/合計を作る

**使う条件：** 年齢・世帯規模・地域・利用強度・商品・曜日/時間帯などに率/量/価格の違いがあり、その差を説明できる。単なる機械的な男女/年代分けを必須にしない。分割の理由がなく仮定だけ増えるなら、単純な代表値と感度を選ぶ。

| 求める量 | 基本式 | 重みを取り違えない |
| --- | --- | --- |
| 全国使用率 | `p = Σ（対象人口シェア w_g × 群の使用率 p_g）` | 研究室/サンプル内の人数比ではなく対象人口比。群内率は観測か仮定かを分ける |
| 保有総数 | `N = Σ（世帯数 H_g × 保有率 p_g × 保有世帯平均 m_g）` | 全世帯平均なら `p_g×m_g` を既に含む。普及率を再掛けしない |
| 平均販売単価 | `平均単価 = Σ（販売本数 q_i × 実支払単価 P_i）÷Σq_i` | 商品数/店数の比で代用するなら追加仮定。価格帯の単純中間や本人の1件の価格とは別 |
| 総支出 | `T = Σ（人数等 × その群の購入頻度 × 群の実効単価）` | 人数で平均した頻度と単価を別々に掛けると、頻度と単価の対応を失う |
| 時間帯の数量 | `Q = Σ（区間の時間 × その区間の実績率/速度）` | 平日/休日は該当日数、映画の占有は上映席回、機種は対応する課金/稼働時間で重み付け |

**平均の中身を説明する枝：** `客単価＝基本額＋追加購入率×追加額`、又は高低群の混合。群は互いに排他的か、異なる取引単位を足しているか確認する。同じ人が缶とカフェを使っても、別の杯の最終購入なら足せる。利用者割合をそのまま杯シェア/金額シェアと呼ばない。

**既存の証拠：** [GYM-003](../learning/2026-11-25-03-gym-stock-ownership.md)参照の `80%×5＋20%×40＝12本/台日` は台で重み付けた平均の説明例。[GYM-009](../learning/2026-11-25-05-gym-sales.md)の `900＋50%×200＝1000円/客` は同問の事後補足で、新観測ではない。[GYM-028](../learning/2026-11-26-04-gym-information-transfer.md)は0台を含む分布と保有世帯平均を分けた。[GYM-027](../learning/2026-11-26-01-gym-additional.md)は全720営業時間、サイクル占有と有料運転の違いを保った。[CM-F-010](../learning/2026-11-26-05-casematch-pc.md)ではstockを絞った後の主体hの整合が不足し、分母補正を最後まで通す必要を得た。各係数の実数は未認定。出典方法：NUM-S04/S05/S09と各演習の代数。

<a id="ns-04"></a>
### NS-04｜近い比較対象・基準率から類推し、差を補正する

**使う条件：** 同じ分母・行動/構造を持つ近い資料/事例があり、違いを少数の説明可能な補正で表せる。最も印象的な1例より、対象条件の近さを優先する。

**手順：** 比較対象の値と条件を固定 → 規模/地域/属性/年/品質/チャネルの差を確認 → 物理/行動上の比例が成立するか点検 → `対象量 ≈ 比較量 × 規模比 × 必要な補正`。調査から別年へ変化なしを置く場合も補正仮定であり、無補正だから仮定ゼロとはしない。

**条件・失敗防止：** 固定費/容量制約がある量を人数・席数に無条件比例させない。生産や所得の増加率を購入価格/頻度へ自動流用しない。単なる補正を統計的に学習/検証済みの回帰式と呼ばない。補正が大きい/多い/方向すら不明なら、別の比較対象か別経路へ切り替える。

**既存の証拠：** [GYM-029](../learning/2026-11-26-04-gym-information-transfer.md)の2021年1.03台/世帯を2026年へ移す処理は「変化なし」の外挿。[CM-F-010](../learning/2026-11-26-05-casematch-pc.md)は二人以上の値を単身へ移さず、単身率を別仮定にした。[GYM-015](../learning/2026-11-25-07-gym-transfer-density-unit.md)は60→150席へ変えても同じ厨房では皿数が2.5倍にならない。類推元と補正のどちらも未観測なら、その組を確認値とはしない。出典方法：NUM-S03/S06。

<a id="ns-05"></a>
### NS-05｜行動・時間・空間・物理/資源の制約から導く

**使う条件：** 率や量を直接思いつきにくいが、利用機会、作業時間、配置間隔、日常行動、物理サイズなどへ戻せる。主要な係数だけ必要な範囲まで分解する。

| 未知量 | 導くための候補 | 使えない/補足が要る条件 |
| --- | --- | --- |
| 利用/購入頻度 | `1週間の機会数 × その機会の利用確率`。利用者限定か非利用を含むか固定 | 週頻度に利用日率を既に含めた後、同じ率を再掛けしない。購入と消費の在庫差に注意 |
| 単価/1回支出 | 基本商品＋追加購入、又はサイズ/チャネル別の実支払×購入構成 | 送料/無料閾値/セットは注文単位で適用。最低〜最高価格の中間を全国平均にしない |
| 1日量 | 稼働時間÷1回時間×1回量、時間帯別の人数/機会 | 理論能力と実需要を区別。既知の実回転/実績量に稼働率を重掛けしない |
| 空間密度 | 線なら間隔、面なら1対象の占有/担当面積、体積なら形状と空隙 | 道路沿いの間隔を国土面積へ直接割らない。必要配置≠現存設置。通路等を二重控除しない |
| 交換/購入量 | 対象stock×同対象の実効年購入率、又は導入世代ごとの到来 | `stock/寿命`は定常・対象・退出等の条件が必要。選択された買替え旧品平均年数の逆数は、全保有の年購入率とは限らない |
| 出荷/完成量 | 在庫収支、同対象平均在庫/平均滞在、工程/材料/注文の制約 | 容量だけから年flowは決まらない。平均能力上限内でも期限内完成・ピーク対応を保証しない |

**既存の証拠：** [GYM-007](../learning/2026-11-25-04-gym-density-area-unit.md)は移動中8h×25km/hで200kmを説明したが実測でない。[CM-F-008](../learning/2026-11-26-02-casematch-capacity.md)は0.5mピッチ/約1.7m/秒の像から200箱/分を置いたが、工場平均を観測したことにはならなかった。[CM-F-009](../learning/2026-11-26-03-casematch-warehouse.md)は同時容量38,400箱と、自由条件による年72万箱を分けた。[CM-F-006](../learning/2026-11-25-12-cohort-transfer.md)は特定年の世代を長期平均で潰さなかった。詳細な更新/時間条件は[B-004/005](stock-time-weighting.md)、幾何/能力の候補は[B-007/008](geometry-capacity.md)へ。出典方法：NUM-S01/S02/S06と既存の条件付き式。

<a id="ns-06"></a>
### NS-06｜上下の目安から代表値を置き、幅の意味を残す

**使う条件：** 一点の直観は弱いが、比較対象・過去の範囲・行動/物理制約により上下の目安を理由付きで置ける。0〜100%のような自明な範囲だけでは設定根拠として弱い。

- **算術の中点 `(L+U)/2`**：差の大小を同じ尺度で扱う暫定中心。左右が同じくらい妥当という仮定が要り、販売平均の証明ではない。
- **幾何平均 `√(LU)`**：`L>0,U>0`で、桁/倍率で上下の距離を同程度と考えるときの暫定中心。確率分布がなければ期待値/中央値の認定ではない。0を含む率や平均単価に万能に使わない。
- **数量/機会での加重平均**：構成がわかるならNS-03を使う。中央値・最頻値・最安値は平均支払価格と別。少数高額の裾が寄与するなら群を分ける。
- **幅の名前**：必ず成立する物理/論理制約、資料に基づく実績幅、自分が置いた単独感度、整合した低/基本/高シナリオを区別する。根拠なしの±20%を信頼区間と呼ばない。

**既存の証拠：** [CM-F-007](../learning/2026-11-25-13-photo-print.md)の利用率/枚数の幅はwhat-ifであり、後に取得した個別料金の最低/最高から全国平均を作れなかった。[CM-F-011](../learning/2026-11-26-06-casematch-takeout.md)では本体構成比の感度が小さな料金比より大きかった。[GYM-018](../learning/2026-11-26-01-gym-additional.md)は自明な国土上限に入るだけで正確としなかった。幾何平均の代表値は今回資料から採用する条件付きの枝で、既存演習で実測精度が上がった実績は未取得。出典方法：NUM-S01/S08。

<a id="ns-07"></a>
### NS-07｜設定例索引から、条件を合わせて補助参照する

**使う条件：** 方法から作った値を照合する、又は直接の導出が難しく、近い過去問/資料の設定を暫定的に借りる。索引は暗記すべき共通基礎知識でも、全て最適と実証された答え集でもない。

**手順：** 対象変数・分母・期間・単位から検索 → 観測値か解答例/自作の仮定か確認 → 元問題の規模・属性・年・用途との違いを点検 → 必要ならNS-03/04で補正 → 元行IDと、今回残す仮定を保存する。

既に答えを知っていてそれへ合う率を逆算した場合は、既知答えへの当てはめと記録する。参照例の同じ値を繰り返したことを独立の再現性へ数えない。異なる解答例の値が離れるとき、条件差を比較せず平均しない。矛盾/修正のある旧設定も歴史資料として索引に残し、現行として無条件利用しない。

**既存の証拠：** [GYM-019/023](../learning/2026-11-26-01-gym-additional.md)では道路延長/猫頭数が既読教材の想起で、独立統計にならなかった。[GYM-028](../learning/2026-11-26-04-gym-information-transfer.md)は既知stock約6000万によるアンカーの影響を明示した。今回の索引化はこの流用を追跡可能にする仕組みであり、索引を使った新規問題/10秒内支援の検証はまだ行っていない。根拠は同演習とNUM-S06/S07の比較・記録原則を本用途へ適用した整理。

<a id="ns-check"></a>
## NS-CHECK｜設定後の確認と、調べ直す優先

1. **何を表す数字か**：対象・分母・条件・期間・単位。全体平均/条件付き平均、人数/世帯/物体/取引、所有/利用/購入を対応させる。
2. **何から出したか**：元情報→今回への橋渡し→丸めた値。説明のある仮定を観測値へ格上げせず、出典にない補正は自分の仮定とする。
3. **整合するか**：率の和/上限、群の非重複、平均の重み、stock/flow、時間/資源上限、課金の二重計上、主要係数同士の依存を点検する。能力以内/非負であることは必要条件の確認にとどまる。
4. **結果へどれだけ効くか**：積の主要係数は、概ね同率変化が同率で結果を動かす。群の一部なら寄与が重みとなる。分母の期間/間隔は逆方向、飽和/minや非線形では式を再計算する。係数の不確かさと寄与の両方を見て、調査対象を選ぶ。
5. **別の根拠があるか**：一単位への戻し/同式再計算は内部確認。別式で価格や基数を共有するなら共有部分を明記。別観測を得ても対象/年/含除が違えばそのまま誤差率を作らない。逆算で店数等を調整して同じ答えに合わせる行為は独立検証ではない。
6. **何が未確認か**：主な自由係数を留保し、条件付き全体回答として完了する。実数精度・未知問の再現性・速さは別途評価し、未検証を隠さない。
