# CaseMatch：家庭の新品PC年購入へ概数を転用する

## 受領条件・事前に使う情報

設問の要点：国内家庭が1年に購入する**新品デスクトップ/ノートPC**の台数。個人利用のみ。期首stockは家庭が利用するPCで、元の購入が新品/中古かは問わない。当年は買替えと追加の新品を数える。企業/学校の業務教育用、中古購入、tablet/smartphoneは除外。係数自由。

- FERMI-FACT-003 **v1**：[概数本文](../details/rough-anchors.md)、SHA256 **941589e039d8c2c4f5642aa8482ba6ee2aed59d7da1b0c27cba34be2be5f57ee**。内閣府の二人以上調査世帯のPC普及74.7%・全調査世帯平均1.228台を知っている。元PC台数のアンカーを調査した後の転用学習で、完全未見の独立留保評価ではない。
- KNOW-JP-002 v1：全国世帯を約6000万で置く。確認した一般世帯約5718万とラフ値を分離する。
- FERMI-SOLVE-B-004/B-005 **情報v2**：stockと新品購入、所有/家庭利用、更新/退出/中古移転、分母の加重と重複の条件付き規則を実読。
- FERMI-SOLVE-B-006 **候補v1**：公表観測から対象への外挿と自由係数、算術の再計算と独立実測を区別する。
- A-001/A-002標準v2。問題受領から全体回答までの共通時間条件による計測は未実施。

## 初回答（講評前・不変）

**結論：国内家庭の新品PC購入は年間約800万台。** 以下の基本模型で約793万台/年。実購入の確認統計ではなく、対象をそろえたstockと行動仮定からの概算である。

### 1. 対象と最初の式

当年に国内家庭が個人利用のために新品のデスクトップ/ノートを購入した物理台数。年度に固定せず平常の1年間という近似とする。企業/学校の業務教育端末、タブレット/スマホ、中古購入を除く。家庭内で学生等が個人用途で買うPCは設問の除外に明示されない限り含むが、学校が教育用として調達する端末は除く。元は中古で入手したPCでも、いま家庭で利用していれば期首stockに入る。

第一候補：`新品購入 N = 既存PCの置換購入×新品比率 + 非保有家庭の初導入×新品比率 + 既存保有家庭の買増し新品`。

「置換」は既存PCの役割を新しいPCへ置き換える購入、「追加」はその役割を維持したまま利用PCを増やす購入とする。1件を両方へ入れない。買替えた後の旧機の廃棄/保管/中古売却/家族への譲渡は別の物理移動で、新品購入件数を増減する係数ではない。

### 2. 期首の家庭利用stockを作る

全国6000万世帯を、単身40%＝2400万、二人以上60%＝3600万と**仮定**。40/60%は本問の自由係数で、今回新しい世帯別構成表は読んでいない。

| 変数 | 値と根拠の性質 | 対象への橋渡し |
| --- | --- | --- |
| 二人以上世帯の全世帯平均PC台数 | **1.2台**。FACT003の内閣府1.228を丸める | 元調査は外国人/学生/施設等入居世帯を除く。全国の該当家庭にも同じ平均を外挿する追加仮定。企業/学校貸与や利用休止の混入は未確認 |
| 単身世帯の全世帯平均PC台数 | **0.7台、仮定** | 同月の単身表は未取得。非保有も含む平均で、既知の二人以上値を無条件流用しない |
| 保有PCを設問の家庭個人利用PCへ合わせる率 | **90%、仮定** | 保管/非利用、対象外の業務教育端末等をまとめて除く代理補正。全国の実測率ではなく、用途が曖昧な元資料との差を残す |

保有代理値 `S_owned = 3600万×1.2 + 2400万×0.7 = 4320万+1680万 = 6000万台`。

家庭個人利用stock `S = 6000万×90% = 5400万台`。全世帯平均台数を使うため、ここへ保有世帯率を再度掛けない。このstockは元の入手が新品/中古のいずれでも数える。

### 3. 置換と追加の新品を合算する

**置換購入。** 現在利用するPC1台が、その家庭で置換購入を起こす年率を `r=1/6` と仮定する。PCの機能/OS/故障/利用目的の変化等で数年ごとに置き換える像だが、観測した寿命ではない。これは**実効的な置換購入率の仮定**で、物理的に全てのPCが6年で国内家庭から退出するという主張ではない。購入世代/当年の更新集中は未確認なので平常近似とする。

置換購入には中古もあり得るため、新品比率を80%と仮定。`N_replace = 5400万×1/6×80% = 720万台/年`。

**初導入と買増し。** 二人以上の保有世帯率75%はFACT003の74.7%を丸めて同対象へ外挿、単身の保有率50%は仮定。保有世帯 `3600万×.75+2400万×.50=3900万`、非保有2100万。これは**買増しの主体分母**のための計算で、stock5400万へ掛けない。二人以上の1.2/.75＝1.6台、単身.7/.5＝1.4台は所有世帯平均への内部換算で、独立観測ではない。

- 非保有2100万世帯の2%が年内に1台初導入、新品比率80%：`2100万×2%×1台×80% = 33.6万台/年`。
- 既存保有3900万世帯の1%が年内に1台を**追加の新品**として購入：`3900万×1%×1台 = 39万台/年`。この1%は新品の買増し率なので、80%をもう一度掛けない。
- 1世帯が同年に置換と追加をすることはあり得るが、同じPCの購入は分類を1つに決める。新規所有世帯を既存保有世帯の買増しへ重ねない。年内の新規世帯形成/解散・初導入世帯の同年2台目等は小さいとして、この模型では別項を置かない。実際の寄与は未確認。

`N=720万+33.6万+39万=792.6万台/年 ≈ 年800万台`。

### 4. 点検・感度と結論

年flowへ進む率は全て1/年で、stock台数をそのまま年販売にしない。新品比率80%は置換/初導入の各購入flowへ掛け、期首stockから「元中古のPC」を落とさない。家庭間の中古移転は国内全家庭stockでは相殺され得るが、企業から家庭への中古流入や家庭の保管/利用復帰は対象境界を越えるため別。**新品買替え＝当年廃棄**と置かない。

物理収支は `期末利用stock = 期首利用stock + 新品の利用開始 + 対象外からの中古/復帰等の流入 − 廃棄/対象外移転/利用停止等`。購入から利用開始の年跨ぎもあり得る。今回その全流入/流出と期末stockは未観測なので、stock一定からNを確定したとは言わない。置換/追加の購買行動を仮定して年量を作った模型である。

| 条件付き感度（他を固定） | 新品年購入 | 読み方 |
| --- | ---: | --- |
| 実効置換間隔を5年 / 8年へ | 936.6万 / 612.6万台 | 率が当年に安定する仮定。物理寿命の統計範囲ではない |
| 置換購入の新品比率を60% / 90%へ（初導入は80%のまま） | 612.6万 / 882.6万台 | 中古選択が大きく効く。現実の分布/信頼区間ではない |
| 家庭個人利用への補正を80% / 100%へ | 712.6万 / 872.6万台 | 保有から利用stockへの橋渡し率は未観測。追加主体の分母は固定した一変数感度 |

1世帯当たり全国平均購入は `792.6万÷6000万≈0.13台/年`。同じ入力からの内部点検で、独立販売統計の裏付けではない。PCの家庭向け小売/POSや出荷の個人向け内訳を、国内購入/輸出入・流通在庫・新品/中古・対象端末にそろえた外部照合は**未実施**。学校/企業を含む全PC出荷と直接誤差率を取らない。

したがって回答は**平常年で家庭の新品PC約800万台/年**。主要な不確かさは利用stockへの補正、実効置換率、新品選択率。約600–940万は示した単変数の模型結果で、実数の上下限や信頼区間ではない。単身/除外世帯への外挿、当年の更新世代、追加行動の実測を補強する必要がある。

### 講評後の補足（原案は変更しない）

対象個人利用PCを持つ家庭数を `h` と別記する。元の3900万保有世帯が全て少なくとも1台の対象PCを残すという条件なら `h=3900万` が使えるが、非利用/業務教育端末しか持たない世帯があるなら減らす必要がある。この条件は原案では置ききれていなかった。

同じ6000万世帯で、対象非保有は `6000万−h`、初導入新品 `(.02×.80)×(6000万−h)`、既存保有の追加新品 `.01h`。元の置換720万を固定した模型では、`N=720万+96万−.006h`。例えば `h=3900万` なら元の792.6万、`h=3500万` なら795万台。これらは**主体対応を明示した修正版の条件例**で、hを新しく観測した結果ではない。数値の差が小さくても、対象を揃える必要は残る。

原案後に[内閣府の買替え旧品年数を再input](../input/2026-11-26-05-pc-renewal-followup.md)した。PC7.7年は買替え世帯だけの旧品平均で、1/6という仮の実効置換率を自動的に1/7.7へ置換する根拠ではない。[FACT003情報v2](../details/rough-anchors.md)へ、所有主体と利用stockの対応、選択付き旧品年数の条件を統合する。新しい同対象販売や年購入率の実証は得られていない。
