## GYM-008：コーヒーの国内年間市場

### 解説前の対象定義・知識適用

国内の最終消費者がコーヒーそのものへ支払う**年間の小売・飲食売上**とする。家庭用の豆・粉・インスタント、缶/PET等、店舗で購入する抽出コーヒーを含む。輸出、マシン販売、菓子等の非コーヒー品、卸売/原料売買の売上を重ねて足さない。喫茶店の食事セットはコーヒーに対応する金額だけを想定する。国内在住者の飲用が主で、訪日客の追加は未推定。

1人が複数チャネルで買っても、**飲用する1杯ごとに購入チャネルを一つへ割り当てる**。各チャネルの利用者割合を足して飲用人数を膨らませない。家庭用は豆等の最終小売額を杯当たりへ換算し、その豆の輸入/卸売や、家庭で淹れた杯に喫茶価格を二重に乗せない。購入と消費が期間内で大きくずれない近似を置く。

### 仮定表

人口・年齢比・日数は保存済みアンカーを丸めたもの。それ以外は本問用の仮定で、確認済みのコーヒー統計ではない。

| 変数 | 値 | 根拠・限界 |
| --- | ---: | --- |
| 在住人口 | 1.2億人 | KNOW-JP-001のラフな値 |
| 主要飲用年齢 | 人口の90% | KNOW-JP-003を使い15歳以上。15歳未満の消費は少ないとして省略する仮定 |
| 飲用する人の割合 | 60% | 好みやカフェイン回避を考え、全員とはしない。実測未確認 |
| 飲用者の平均頻度 | 1.5杯/日 | 毎日複数杯と時々飲む人を均した仮定。非飲用者は含まない |
| 年間日数 | 360日 | KNOW-JP-006。営業日ではなく日常の飲用日 |
| 家庭/職場等で淹れる杯の割合・小売相当額 | 60%、30円/杯 | 多くは安価な自家抽出と仮定。原料小売額を杯へ換算した額。機械や光熱費を含めない |
| 缶/PET等の杯の割合・価格 | 25%、150円/杯相当 | 1購入単位を概ね1杯として近似。大容量製品の杯数換算は粗い |
| 抽出済みを店頭等で買う割合・価格 | 15%、300円/杯 | 喫茶・持帰り等の平均。高単価店とコンビニ等の差はこの平均へ集約 |

チャネル割合60%+25%+15%=100%。課金対象は杯当たりに統一する。家で買う豆と外で買う飲料の価格差を、同じ「平均単価」で隠さず確認できる形にする。

### 式・計算・結果

飲用者 = 1.2億人×90%×60% = **6480万人**。

年間杯数 = 6480万人×1.5杯/人日×360日 = **349.92億杯/年**。

加重平均価格 = 60%×30円+25%×150円+15%×300円 = **100.5円/杯**。

年間売上 = 349.92億杯×100.5円/杯 = **3兆5166.96億円/年**。チャネル別には約6300億、1兆3100億、1兆5700億円で、合計約3.5兆円。元の率・頻度が粗いため、結論は**年間3～4兆円程度、基本値約3.5兆円**とする。この3～4兆は表示上の丸めた規模感で、統計的区間ではない。

### 点検・感度・別経路

- 単位：人×無次元×杯/人日×日/年×円/杯 = 円/年。飲用率を掛けた後の1.5杯は飲用者限定の頻度であり、もう一度飲用率を掛けない。
- 1人当たりへ戻すと全国平均約2.9万円/年、飲用者当たり約5.4万円/年、月4500円程度。家庭のみの人にも全員この額を使うという意味ではない。価格の高い外部購入が売上を大きくする構造を確認したもので、独立検証ではない。
- 頻度だけを1～2杯/日とすると、約 **2.3～4.7兆円/年**。他条件は固定。
- 缶/PETの25%を固定し、家庭と抽出済み購入の間で10ポイントを移すと、平均単価は73.5～127.5円、売上は約 **2.6～4.5兆円/年**。どのチャネルで消費するかが金額へ大きく効く。比率を変えた分だけ他の比率を補正し、和100%を維持する。
- 別の月次支出像：飲用者1人が自家抽出30杯×30円、缶等8杯×150円、店頭5杯×300円で月3600円。6480万人×3600円×12か月 ≈ **2.8兆円/年**。杯数・チャネル構成が主経路と異なるが価格アンカーは共通で、完全に独立したデータ検証ではない。
- 主経路と月次像の差は、主経路の月45杯程度のうち高単価チャネルが相対的に多いこと等で説明できる。どちらも実測未確認なので、一致へ調整したり平均して正答としたりしない。

結論は約3.5兆円/年。主要な不確実性は飲用率・頻度・最終購入チャネルの構成と単価。訪日客・15歳未満・在庫変動・大容量製品の杯数換算は省略の影響が未評価。最終小売額という定義を保ったまま解説と比較する。

## GYM-009：駅前ラーメン店の月商

### 解説前の対象定義・知識適用

1店舗・通常月・店内飲食の売上を推定する。駅前の中規模店を想定し、通販・宅配・持帰り等は対象外とする。客単価はラーメンと平均的な追加注文を含む支払額で、売上と利益を混同しない。同じ客の別日の再来店は新しい取引として数える。席数や営業時間等は与件ではなく自分の仮定。

| 知識ID・版 | 実際の適用箇所 |
| --- | --- |
| FERMI-SOLVE-A-001/B-002 v1 | 1店の売上を席・理論回転・稼働・単価・営業日へ分解。人口から全国需要を置く方法は使わない。 |
| FERMI-SOLVE-A-002 v1 | 理論最大と実際の利用、厨房の上限、単位・月次換算、感度・需要側の別経路を点検。 |
| FERMI-SOLVE-B-003 v1 | 実人数でなく来店取引数、1店の通常月という境界を固定。GYM-002での時間平均の弱点を受け、昼/夜を別に積み上げる。 |
| KNOW-JP-006 v1 | 月30日を丸めの起点とし、約4日休むという仮定から26営業日へ。30日と暦日数を無意識に混ぜない。人口等のアンカーは不要。 |

### 仮定表と主計算

以下は全て本問のための仮定で、実際の店舗観測ではない。稼働率は満席でない時間も平均した席の利用率。1回転時間には入替・片付けを含む。

| 変数 | 昼 | 夜 | 根拠・留保 |
| --- | ---: | ---: | --- |
| 席数 | 20席 | 20席 | 駅前のカウンター等を含む中規模の1店 |
| 営業時間 | 3時間 | 5時間 | 昼11～14時、夜17～22時を想定 |
| 1回転時間 | 0.5時間 | 2/3時間 | 昼は短く、夜は追加注文等で長いと仮定 |
| 席の稼働率 | 80% | 50% | 昼に集中し、夜は平均すると余裕がある想定 |
| 席からの利用見込み | 20×3/0.5×80%=96客 | 20×5/(2/3)×50%=75客 | 最大回転に一度だけ稼働率を掛ける |
| 厨房の提供上限 | 30食/時 | 30食/時 | 調理・盛付・提供を合わせた処理量の仮定。1客1食相当を置く |
| 客単価 | 1000円/客 | 1000円/客 | 基本の1杯約900円＋平均的追加約100円という像 |
| 月間営業日 | 26日 | 26日 | 月30日から約4日休む近似 |

席側の利用見込みは昼32客/時だが、厨房の30食/時を超える。このまま96客を採用すると、置いた条件の間で矛盾する。待ち行列で翌時間帯へ持ち越す効果は扱わず、処理上限による制約として**昼は30×3=90客**とする。夜は15客/時なので厨房上限を超えず75客。

式：

`月商 = Σ時間帯 min（席数×営業時間÷回転時間×稼働率、厨房提供上限/時×営業時間） × 客単価 × 営業日`

`= (90+75)客/日 × 1000円/客 × 26日/月`

`= 429万円/月 → 概数で約430万円/月`。

ここでminを取るのは、席側の利用見込みと厨房処理の制約を重ねた簡易モデル。実際の需要が十分ある証明ではなく、需要を席稼働率に織り込んだ仮定である。調理30食/時も実測でないため、これを事実上のボトルネックと断定しない。

### 点検・感度・別経路

- 厨房を見ずに席だけなら171客/日、月444.6万円。厨房を加えた165客/日の約430万円との差は約4%。違いは今回の仮定間の整合によるもので、売上を上げる施策を評価したわけではない。
- 165客を8営業時間で均すと約21客/時。1日最大は昼90+夜150=240客（月624万円）という同じモデル内の制約なので、推定が最大供給を超えていない。上限内にあるだけで需要が正しいとは言わない。
- 客単価だけ900～1200円なら **約390～510万円/月**。
- 夜稼働率だけ35～65%なら、夜52.5～97.5客、月商は **約370～490万円/月**。平均人数の小数は期間平均の計算上の値で、実際に半人を提供するという意味でない。
- 昼稼働率を60～90%へ振ると、昼72～90客、月商は **約380～430万円/月**。高い側で売上が頭打ちになるのは厨房上限を固定したため。
- 別の需要側像：営業8時間に店前を平均0.5人/秒が通ると14,400通行イベント/日。その20%がその時間の飲食候補、候補の5%がこの店を利用すると144来店/日。×1000円×26日 ≈ **370万円/月**。
- 通行イベントは同じ人の再通行も含む。来店へつながる機会の割合として置いたもので、一意な地域人口を使っているわけではない。通行速度・食事候補率・捕捉率は全て仮定で、完全な独立データではない。主経路の165客との差を無理に合わせない。

結論は店内飲食だけで**月商約430万円**、単価・夜需要・昼の処理能力によって数百万円台で動く。主要な未確認点は駅前の人流の実態、席稼働、厨房能力、休日の需要、追加注文、持帰り等を含める場合の別売上。売上から家賃・原価等を引いた利益は本問では求めていない。
