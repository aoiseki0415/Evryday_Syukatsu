## 役割

①で導いた回答全体を土台に、本人が短時間で認識できる形で初回共有する。当面は**ノータイムフェルミ**が前提。[現行方針の要約](CORE.md)を最初に読み、仕様本文へ進む。

**準備 → お題を受領 → ①で全体回答を構築/確認 → 初回共有。**

| フェーズ | 独立した仕様本文 |
| --- | --- |
| 全体の順序/適用範囲 | [workflow](details/workflow.md) |
| 準備：読む内容/順/重み/完了条件 | [preparation](details/preparation.md) |
| お題受領から初回共有：表示形式/短い理由/速度 | [initial-response](details/initial-response.md) |

初回共有後の唐突な質問への具体的対応は、後日議論する。ケース②の仕様を変更するものではない。

## 情報の置き場

- [INPUT](INPUT.md)：読むべき情報・教材の索引と収集状態。実際の資料ノートは、受領後にinput/へ追加する。
- [LEARNING](LEARNING.md)：演習・評価の方法と記録先。演習実績は実施後にlearning/へ追加する。
- [CURRENT](CURRENT.md)：CORE・INDEX・詳細へ案内する入口。採用情報の本文をここに重複管理しない。
- 全保管項目の正本は[INFORMATION_MAP](../../../INFORMATION_MAP.md)、移行状態は[READINESS](../../../learning/READINESS.md)。

情報を読むinput、場面で確かめる学習、現行仕様を分ける。合意した仕様の採用と、検証による支援品質の確認も別。対話証拠は[sessions](../../../sessions/README.md)、評価は[LEARNING](LEARNING.md)、経緯/旧案は[HISTORY](HISTORY.md)から読む。
