# ケース②｜本人への支援：学習・評価

状態：開始前。ケース①・フェルミ①の十分な精度を[READINESS](../../../learning/READINESS.md)で確認してから開始する。今回は置き場と要件のみを整備。

## 開始後の進め方

1. ①の回答全体と現行の知識・解法を土台として用意する。
2. お題の文字/画像入力、初手提示、途中で変更条件や部分依頼を受ける支援場面を試す。
3. 本人から使いやすさのフィードバックを受ける。対象：認識の速さ・正確さ、初手の適切な範囲、表現と長さ、応答時間、本人の現在地との一致、不要な先回り・確認の有無。
4. ①の解答内容の誤りと、②の切り出し・伝え方・適応の問題を区別する。①に問題があれば①の教材評価へ戻し、本人に正誤採点を依頼しない。
5. 提示前後の比較と評価を残し、採用した支援ルールをdetails・INDEXへ反映し、採用済みAはCOREへ要約する。

## 記録先と項目

学習の評価はlearning/YYYY-MM-DD-NN-topic.md。learning_id、mode/layer、①の参照版、場面、表示内容の参照、本人の現在地と不明点、本人の評価、計測した応答時間、修正と再評価、採用/保留/撤回を記す。

対話・表示そのものの正本は[sessions](../../../sessions/README.md)に置き、ここから参照する。①の想定と違う本人の進み方を誤り扱いせず、共有された現在地を優先して支援を組み直す。
