## CASE-SOLVE-A-001：回答全体を作る共通骨格

**決める問い → 必要な論点と仮説 → 根拠・計算 → 選択肢の比較 → 条件付きの結論と検証。** 次の順序は思考の整理であり、情報を得るたび前へ戻って更新できる。

1. **問いを固定する。** 誰が何を決めるか、評価指標、期間・対象、制約を短く言い直す。売上/利益額/利益率/キャッシュ/市場規模/社会成果、注文/延べ客数/実人数を区別する。意思決定前に変えられるものと導入後/契約中に変えられないものも保持する。質問ができない練習では不足を仮定として表示し、分岐する。
2. **与件を保持して構造を選ぶ。** 必要な式または論点を置き、どの枝を先に見ると決定に効くかを説明する。フレーム名を並べる代わりに、枝が問いへどうつながるかを示す。新情報で枝を変更する。
3. **仮説を事実へ変えない。** 与件/確認済み事実、置いた仮定、そこからの計算、原因仮説を区別する。原因AとBを見分けるデータ・反証を置く。「なぜ」を重ねた物語だけで真因を確定しない。
4. **意思決定に必要な量を出す。** 式→単位→代入→計算→示唆をつなぐ。市場規模だけで自社売上を断定せず、需要・シェア・処理能力・成長速度を確認する。ケース内の推定も同じケース①として扱う。
5. **施策を作用と結果で比べる。** 課題/原因→何を変える→指標への経路→期待便益・増分費用→実行条件・リスクを結ぶ。現状維持も比較し、複数施策の重複・相互作用・投資制約を確認する。既存客への値下げ損、チャネル/店/時間の移転、回避できない固定費を無視して便益だけを足さない。能力の上昇率、時間の削減率、費用の削減率も定義して区別する。
6. **決めて、壊れる条件も示す。** 推薦、決定的根拠、残るリスク、成立条件、次に確認する事項を揃える。追加調査の列挙だけで結論を避けない一方、情報不足で断定もしない。
7. **回答全体を検証する。** 問いに答えたか、与件を破っていないか、百分率・桁・単位・年次が合うかを確認する。施策後の最終指標と目標を比べ、未達なら不足量を示す。低効果/悪条件や反対仮説で結論が崩れる条件を確認する。解答例との数値一致だけを検証にしない。

根拠：CASE-WEB-01/02/03/04/05/06/07/15/16の共通点を統合し、CM-C-002/003、GYM-C-002/005/010、GYM-C-011〜014で使用・照合した。投資/価格はCaseMatch文章講評、他はジム解説との自己比較。型の選択・全体の構成・定義・検算を標準手順にする根拠であり、効果仮定の実証ではない。細かな手順・分類はCodexの整理。会話の見せ方・口頭の長さなど②の最適化はここで採用しない。

### 売上・利益・回収を混ぜないための式

以下は式の定義からのCodexの代数整理。個別企業の需要関数・会計上の費用認識を保証するものではない。

- 売上 **R = Σ(p_i × q_i)**。客数×客単価の場合、頻度や点数が客単価/客数に既に含まれるか確認し、二重に掛けない。
- 単純な単一商品の利益 **π = (p−v)q−F**。vは単位当たり変動費、Fは対象期間の固定費。初期投資Iを同じ期間の費用にするかは、設問の回収目的・費用認識に合わせて明示する。
- 価格上昇率r、数量減少率dの売上比 **R1/R0 = (1+r)(1−d)**。増収には **d < r/(1+r)**。率の単純比較は交差項を落とす。
- v一定、追加固定費ΔFなら、値上げ後利益の改善条件は **(p(1+r)−v)q(1−d)−(p−v)q > ΔF**。数量だけでなく費用・商品構成が変われば再計算する。
- 単位限界利益p−vが正なら、営業の損益分岐量は **F/(p−v)**。初年度に投資全額の回収を求める単純モデルなら **(F+I)/(p−v)**。この2つを同じ「損益分岐」として曖昧にしない。
- 施策の効果は同一ベースの増分で比較。施策Aで増えた顧客に施策Bの単価改善も及ぶなら相互作用を計算し、与件が単純加算を指定する場合はその条件を保持する。
- 利益率が目的なら **m1=(π0+Δπ)/(R0+ΔR)**。R0+ΔR>0の下で元率m0を上げるには **Δπ>m0ΔR**。利益額だけの増加では不足する場合がある。[KNOW-METHOD-002](../../../../shared/knowledge/methods/measurement-boundaries.md)を参照する。
- 処理能力がa倍になり、同じ仕事の支払費用が必要時間に比例する場合の費用は元の1/a。能力25%増なら1/1.25で20%減に相当し、「25%費用減」とは異なる。固定給等が変わらないなら支出減ではない。[KNOW-METHOD-003/004](../../../../shared/knowledge/methods/measurement-boundaries.md)の条件を読む。

### 施策の保存・選別の最小単位

「DX」「広告」「値上げ」だけでは情報として不十分。**課題/原因 → 対象顧客/工程 → 変える行動・機能 → 指標への経路 → 成立条件 → 効果/費用 → リスク・確認方法**で一つのカードにする。

例は作問上の一般仮説であり、実企業で効果が実証された事例ではない：継続利用の離脱が問題なら、離脱段階/理由を確認し、使い方の支援や機能修正等を原因に合わせる。値引きは継続率だけでなく限界利益・既存客への割引損・獲得費を含めて比べる。原因未特定なら複数仮説と検証を示す。

事業環境の確認先例としてCASE-WEB-17は、同じ値上げでも企業のコスト、顧客の節約、競合によって方針が異なると報告している。これは施策の条件を調べる手掛かりであり、特定企業の需要減率や施策効果の入力値にはしない。企業の実際の対応・成果は別途公式資料で保存する。

## 演習での使い方・評価と残る検証

- 使用前に **CASE-SOLVE-A-001 v2 / CASE-SOLVE-B-002 v2と枝の状態** を記録する。使用したC番号、式、必要ならB-003/004/005、どの判断に使ったかを初回答に対応付ける。過去の初回答は当時のv1/候補のまま保持する。
- 問題と条件だけを受け、全体回答を保存してから解答例・講評を読む。修正版で初回答を上書きしない。
- 講評で型の誤選択、根拠不足、数量/率の混同、費用・能力・制約の見落としを確認し、どの枝・確認項目を変えたかを残す。
- 各型の中に残る未評価の分岐や追加条件を、別の1問の成功から検証済みにしない。全体回答の作成時間は実測しなければ未計測。
- 次の優先検証：専用3問後も実需/独立留保が不足するC3、独立読取が未評価のC8、多様な公共/社会、閉条件各1問を超える複雑なM&A/撤退、複雑な能力/時間条件、修正後のルールを使う留保問題。今回の[GYM-C-022の時間制約不備](../learning/2026-11-26-01-gym-additional.md)とCM-C-013の事前閾値/投入比較の要改善は原案の不足として保持する。順序は弱点に応じて変更し、問題数だけで高精度認定しない。
