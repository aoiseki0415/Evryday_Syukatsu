# ケース①｜回答全体を解く：学習・評価

状態：2026-11-25、SOLVE-CYCLE-001で初期input→新規学習14問（CaseMatch4・ジム10）→講評/解説比較・修正→差分からの再inputを実施。過去の操作試行1問は別に保持する。全件は[演習台帳](../../../learning/EXERCISES.md)。新規14問は学習用で、事前留保した未見評価・①全体の十分な精度確認は未実施。本人に正誤判定を求めない。

## 進め方

反復の共通手順は[①実行仕様](../../../learning/SOLVE_WORKFLOW.md)を正本とする。[カバレッジ](../../../learning/COVERAGE.md)の不足と[サイクル再開点](../../../learning/CYCLES.md)を読んで開始し、inputで得た知識の実適用→照合→更新→次のinputを結ぶ。

1. 教材の問題ID、解答・解説・採点基準、学習用/評価用の区分を記録する。
2. 解答を先に見ずに、使用する解法・知識の版を固定して回答全体を作る。前提・論拠・確認可能な計算と結論を残す。
3. 問題集の解答・解説等と観点別に照合する。対象：問いへの適合、与件・前提、解法選択、分析と根拠、施策と原因の対応、比較、結論の一貫性。
4. 一致、妥当な別解、誤り、未評価を分け、差の理由と根拠を記録する。Codexの自信だけで正解としない。
5. 誤りの原因と修正案を整理し、別の問題・未見評価でも確かめる。解説を見た問題の再現と区別する。
6. 検証できた内容をdetails・INDEXと対応知識へ反映し、採用済みAはCOREへ要約し、[READINESS](../../../learning/READINESS.md)に評価範囲と未解決点を集約する。

## 記録先と項目

演習開始時にlearning/YYYY-MM-DD-NN-topic.mdを作り、初回答・評価・修正の各節目で保存する。exercise_id、source_id/問題ID、手順版、解答閲覧前の全体回答、参照した解答箇所、採点観点と照合、誤りと原因、修正、別問題の結果、採用/保留/撤回、details・INDEX・COREの反映先を残す。

[演習ひな形](../../../templates/EXERCISE.md)に沿い、使用した知識ID・版・使った箇所、解答閲覧との前後関係、全体回答までの所要時間/未計測も記録する。初回答は修正版で上書きしない。各節目で保存し、継続サイクルを実施する場合はcycle_idから結ぶ。

ここが①演習の正本。sessionsへ同じ回答を全文コピーしない。根拠不足の結果は未評価とし、高精度の確認に算入しない。①の十分な精度を確認する前に②の練習を始めない。
