## 初回答（保存後不変）

**「仕事で初めて表計算を使う成人向け、4週間の小集団オンライン実践講座」をB2C・1コース売切りで試す。最初から通年展開せず、300万円で需要の一次確認、次に小規模有料提供を行い、成立条件がなければ止める。** 国内成人が自分で支払うモデルであり、企業向け長期伴走/サブスクリプションではない。既存製品や販路、成果の実績はない。

### 顧客・価値・代替

対象は基本的な集計/表の作成を業務で必要とするが、独学で完成へ到達しにくい初心者、という仮説。困り事は知識の網羅性より「自分の作業を形にできない」ことと置く。無料動画/書籍/同僚の支援と比べ、短い課題、質問と添削、職場で使う想定の成果物までを提供する。実企業の機密データを持ち込まず練習用の架空データを使う。資格/就職/生産性改善を保証せず、対象技能/必要環境/対象外を明示する。

1コース定員20人、週1回のオンライン回と課題4本、料金3万円/人を仮置き。本人の支払意思、参加可能時刻、代替の不足を面談と価格を見せた募集で確認し、有料の提供完了まで追う。申込や無料登録を需要証明にしない。

### 初年度の収益・予算

1〜2月は調査/試作、3・4月に各20人の有料試行、条件成立なら5〜12月に各20人、計10コース200人を上限計画とする。参加者数は実績でなく仮説。純料金3万円、1人当たり変動5000円（決済/教材等）として、変動費に含めたものを固定費へ重ねない。

| 年間の仮計画 | 万円 |
| --- | ---: |
| 売上200人×3万円 | 600 |
| 変動200人×0.5万円 | 100 |
| 5人の人件費 | 1500 |
| 外部制作/品質確認・教材 | 300 |
| システム | 200 |
| 調査/集客 | 200 |
| 管理等 | 100 |
| 実支出合計 / 損益 | **2400 / −1800** |
| 予備費（未使用なら費用でない） | 300 |

予備費を全て使っても2700万円で3000万円内。売上入金に依存して予算を満たす計画ではない。初年度は利益事業として完成せず、有料需要と提供モデルの検証投資である。この赤字を隠して成功とは呼ばない。

### 5人と月別実行能力

担当5人を、事業/会計、顧客調査/募集、教材/講師、添削/品質、システム/受講運営へ各1人とし、各月100h利用できると仮置き。人件費1500万円は5人×月25万円×12か月。契約/技能/採用可能性は未確認。

教材/講師は前2か月各100hで基礎教材、以後は月の講座/準備12h＋改訂/支援60h以内。添削は20人×4課題×15分＝月20h、品質/対応を月60h含めても80h以内。他担当も調査/募集・設定/運営・会計/調整を各月100h内へ割当て、実行前に月別業務表と兼務/休暇を確認する。外部制作300万円は編集/品質の委託分で、添削を二重外注した額ではない。1月/2月は有料講座を同時開催せず、初期制作と提供を重ねない。

### 検証・停止・継続判断

最初の2か月の上限300万円は人件費250万円＋調査50万円の内数。採用/委託/システムの長期拘束を作らず、停止時の解約費・支払義務を含め300万円で止められる契約か確認する。できなければ初期人数/契約を変える。次段階も通年分を一括確約しない。

検証は①3万円で実際に買う層へ到達できるか、②予定工数内で完了・基本課題を自力再実行できるか、③返金/支援/集客の費用を含む単位採算、の3つ。課題完了と実業務成果は別で、職場成果の因果改善を断定しない。受講月別の離脱/質問/工数を追い、未回答を成功扱いにしない。

現行単位限界利益2.5万円では年間固定2300万円の回収に**920人**必要で、計画200人を大幅に上回る。大量集客を仮定して継続せず、再利用教材/提供工程、実現価格/費用、許容できる提供量を改めて検証する。固定費が全て翌年消えるとは置かない。

各段階の追加は、その時点で止める案に対して、残期間の追加売上/提供費・追加固定/撤退義務を比較する。過去の売上や既払300万円を次の回収に再使用しない。有料満席でも、提供工数や将来採算に道筋がなければ200人への拡大/翌年継続を見送る。本人の支払/学習価値と、資金・技能制約を満たす現実的な採算モデルが見えた場合だけ限定継続する。

**結論：成人向け4週実践講座を小さく有料検証し、初年度3000万円/5人内の上限計画は用意するが、200人規模では黒字化しない点を継続判断の中心に据える。**

## 追記修正版｜事前の判定カード

以下は講評後に追加した**本事業の仮判断基準**で、初回答にあった内容/一般的な成功率/統計的十分性ではない。

1. 初期300万円内で顧客の具体的作業/支払者/代替の不足を記録し、次の20席試行の価格3万円を明示して募集できるところまで進める。申込/返金可能な予約は確定支払証拠と分ける。次段階の拘束/総額が上限を破るなら進まない。
2. 有料試行の仮目標を20席中16人以上の実支払、16人中12人以上の課題完了・10人以上の自力再実行と置く。これは提供モデルを試すための仮最低目標で、利益分岐/市場全体の需要証明ではない。課題基準と未回答/返金を事前定義し、未達なら対象/価格/教材等を改訂して再試行または中止する。
3. 実際の20人当たり添削20h、講師/準備12h、各担当月100hの境界を測る。低い試行人数の工数をそのまま20人へ外挿せず、質問の偏り/欠席振替/習熟差も計測する。実費が仮変動5000円を超えれば限界利益を再計算する。
4. 通年へ広げる意思決定では、**検証価値に支出する上限と、追加採算を要求する本展開を分ける**。現在モデルは200人で赤字なので、満席だけで本展開しない。残期間の追加便益/支出・能力・契約拘束で本展開案が成立しなければ、追加の検証範囲を絞るか停止する。
5. 920人は固定2300万/限界利益2.5万を固定した算術閾値。例えば46コースなら添削だけで920h、講師/準備552hとなり、既存業務/制作/支援を加えて各担当月100hに入るか別に評価する。増員/外注・広告/システム費が変われば固定/変動費と分岐人数を再計算し、920人なら無条件に黒字化可能とは扱わない。

次inputは実際の募集/支払・成果の判定、返金/離脱、担当別の月次負荷と費用。修正版のサイト再評価は未実施。[B-008候補v1](../details/new-business-design.md)への改訂候補は「各重要仮説の事前閾値と、分岐人数での提供容量/費用を再計算する」ことで、本文採用/版の更新は親担当が判断する。

## 親レビュー後の追加改訂｜最大枠と低コスト代替

**3000万円/5人は上限で、全枠の利用義務ではない。** 原案は200人の検証に固定2300万円を置き、赤字1800万円を検証投資として許容するだけでは、機会費用/もっと安い検証との比較が弱い。この不足も結論/実行の要改善へ含める。根拠を[小さい検証の再input](../input/2026-11-26-02-small-tests-followup.md)で補った。以下は原案を置換しない追加の自作仮定。

低コスト案：中核2人（各月100h、月20万円/人）と品質専門家1人の短期外注で同時最大3人。年間固定は中核480万、外部品質100万、システム40万、調査/集客100万、管理30万＝**750万円**。変動は同じ5000円/人、年200人なら100万、売上600万で損益**−250万円**。予備150万を加えて最大支出1000万円となり、元の予備込2700万円より安い。安い案が同じ検証/品質を満たせるかを確認しなければ優位確定ではない。

中核の講師/添削は前2か月各100hで試作、以後1コース月に講師/準備12h＋添削20h＋支援/改訂30h＝62h。もう1人は募集/運営/会計等を月90h以内。品質専門家は年200h以内/月最大30h等を仮置きし、固定100万の実見積り/技能と整合させる。委託へ移した仕事の品質・受渡しを落とさない。

初期2か月は、2人の人件80万＋専門家30万＋システム/調査/管理等90万以内で**200万円上限**へ抑える仮案。将来の採用/契約拘束を含め止められることが条件。面談/試作だけのさらに安い案は価格受容/有料提供を十分検証できないため、段階を分けて使う。

この案でも分岐は固定750万/限界利益2.5万＝**300人**で、200人計画では100人不足。15コース/年へ増やす際のピーク月/獲得費用・品質を再計算する。講師等は月2コースなら32h×2＋その他30h＝94hという単純上限があるが、日程/質問集中と募集の実現を保証しない。固定/変動が増えれば300人も再計算する。

改訂結論は、まず低コスト案で同じ仮説を検証できるかを確認し、十分ならこの案を第一候補にすること。安い案でも支払/成果/実工数と追加採算が成立しなければ止める。原案の5人体制と赤字1800万円を、上限内だから必要/最適と正当化しない。この同題改訂は新規成功/再評価済みではない。
