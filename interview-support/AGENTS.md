# この領域で作業するCodexへ

- 本領域はケース面接・単独フェルミ推定を、Workの会話で支援するための文書・知識・学習基盤。アプリ開発を始めない。
- 最初に[START_HERE](START_HERE.md) → [SPEC](SPEC.md) → [OPERATIONS](OPERATIONS.md)を読み、モード別PLAYBOOKと[採用済みの学び](learning/CURRENT.md)へ進む。未策定の手順を完成済みとしない。
- ケース内の推定はケースモードのまま。単独フェルミのモードは推定そのものが単独出題された場合のみ。共通知識を重複管理しない。
- 編集はinterview-support/配下と[指定Notionホーム](https://app.notion.com/p/423161f2809781ff9677d9f3c6a9e488)配下だけ。親HANDOFF・ログ等も勝手に更新しない。親のGit対象確認・公開範囲・既存変更保護は継続する。
- 細かい節目で保存し、現行確定、議論、過去、提案、実践の証拠を分ける。正本を定めリンクする。Notionは本人向けに図・表を中心として最新のエッセンスを示す。
- 指示済みの調査・整理・更新・支援に追加承認を求めない。未着手の指示を守り、実行環境の強制手続きは回避しない。
- 現在（2026-11-25）は全体構造・運用の整備段階。Web収集、会員サイト利用、解法・知識のinput、問題演習はまだ実施しない。後続の本人指示を反映する。
- 学習は「問題 → 回答例・本人の評価や共同検討 → 改善記録 → 次回へ適用」を中心とする。モデル自体の訓練や実証済みの精度向上とは区別する。
- 終了前に記録・現行正本・Notion要約を整合し、読み戻し・差分確認・本領域だけのコミットとpush・remote一致確認を行う。変更のない会話に空ログを作らない。
