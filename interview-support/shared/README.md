# 2モードの共通基盤

支援モードは分けるが、解法・知識・探索経路・実践からの学びはつなぐ。

| 領域 | 保存先 | 役割 |
| --- | --- | --- |
| 解法・前提知識・施策例 | [knowledge](knowledge/README.md) | 適用条件・出典・時点とともに共有 |
| 必要時の情報探索 | [research](research/README.md) | 早く調べ、事実と見解を分けて共有する経路 |
| 実践からの改善 | [learning](../learning/README.md) | モード別/共通の適用範囲と検証状態 |

2026-11-25現在、両①の本格inputと演習・再inputを反復中。共通の概数・企業事例・集計/収益/工程の確認規則を[knowledge](knowledge/README.md)へ登録した。資料の読解範囲、方法の採用範囲、各問の正確さ、全型の十分な精度は別に確認する。実施一覧は[演習台帳](../learning/EXERCISES.md)。

[materials](materials/README.md)に教材の所在と解答・解説の有無を登録し4領域から共有する。①は教材、②は本人の支援品質の評価を中心にする。
