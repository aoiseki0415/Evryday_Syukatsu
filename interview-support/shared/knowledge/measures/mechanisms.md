# 課題・作用・条件で使う施策事例

版：2026-11-25 v1。対象：ケース①（推定を含む）。企業公式の公開資料を当日確認した事例集。資料読解過程は[資料ノート](../input/2026-11-25-facts-measures.md)。企業の報告とCodexの転用仮説を分ける。

**状態の意味**：下記4件は「公式資料に当該の取組・報告がある事例」として採用済みB。優先度理由は、特定の原因を持つ問題で施策候補を増やせるため。成果の再現性、単独施策の因果効果、他社で同率の改善が出ることは未検証。横展開の条件・KPI・リスクはCodexの仮説であり、演習で検証する。

## 事例と転用条件

### KNOW-MEASURE-001：在庫の可視化を、補充・販売の行動へ結ぶ

- **事例事実／採用済みB**：ファーストリテイリングの2025-4-10説明資料は、RFIDで商品の所在や店頭欠品SKUを確認し、業務アプリで品出し等を把握する仕組み、店舗・EC在庫の一元化を説明している。確認できた成果は情報把握と業務の変化についての企業報告。RFID単独による売上増加率は同資料の該当箇所からは確認していない。[公式説明資料 p.7](https://www.fastretailing.com/jp/ir/library/pdf/20250410_Tambara.pdf)
- **課題→施策→作用の転用仮説**：需要があっても商品を見つけられない／補充判断が遅い → 在庫精度・所在・欠品を可視化し補充ルールまでつなぐ → 販売可能な在庫が売場に出る／他拠点在庫を販売につなぐ → 機会損失や探索時間が減る可能性。
- **成立条件**：SKU識別とデータ精度、担当者・補充締切、配送/品出し能力、需要の存在。画面を導入するだけでは作用しない。
- **評価KPIと費用／仮説**：棚欠品率、在庫差異、補充時間、欠品に起因する失注額、値下げ・滞留在庫。タグ・機器・統合・運用教育の費用と増分粗利を比較する。
- **例外・リスク**：真因が需要不足・品揃え不適合なら優先度が下がる。在庫が共通表示されても引当競合や返品がある。企業の業務改善説明を売上への因果証明に変えない。

### KNOW-MEASURE-002：自動化を、動線・役割分担・現場定着と組み合わせる

- **事例事実／採用済みB**：すかいらーくの統合報告書2024は、採用難を見据えた配膳負担軽減を課題に、機種実験、利用データ、現場指導者による運用改善を記載し、約3000台の展開と顧客満足の報告を示す。[公式DX章](https://corp.skylark.co.jp/Portals/0/images/ir/section/2024/04_dx.pdf)。会社説明資料のガスト指標には片付け時間35%減・歩行数42%減が載るが、該当箇所では比較期間・標本・他施策の調整を確認できない。[公式事業資料「フロアサービスロボット導入」](https://corp.skylark.co.jp/Portals/0/images/about/business/skylark_business_jp.pdf)
- **課題→施策→作用の転用仮説**：移動・運搬が繁忙時の制約 → 自動運搬＋導線調整＋人の役割再配置 → 単位時間の配膳/片付け能力が増す → 待ち・残業・取りこぼしを減らす可能性。
- **成立条件**：移動可能な幅・段差・混雑、十分な運搬頻度、人が残す接客/積み下ろし作業、機器稼働・保守、現場教育。厨房や席数が真の制約なら回転率は上がらないことがある。
- **評価KPIと費用／仮説**：工程別分/客、ピーク待ち、提供遅延、回転数、利用回数/稼働率、顧客満足、総人時。購入/リース・保守・運用時間を含める。歩数減を同率の人件費削減としない。
- **例外・リスク**：機器を置いたまま使わない、事故・停止、サービス品質悪化、余剰時間が再配分されない。上記35%・42%を演習先の改善率として無根拠に代入しない。

### KNOW-MEASURE-003：期限切れの発生を、販売順序・商品設計から減らす

- **事例事実／採用済みB**：セブン＆アイの公開ページは、すぐ食べる客への「てまえどり」呼びかけ、製造・温度・衛生管理を通じた長鮮度商品の開発を説明する。2025-2末でオリジナルデイリー商品の約87%に24時間以上の販売期限があると報告。87%は商品構成の指標であり、廃棄削減率ではない。[公式食品ロス対策](https://www.7andi.com/sustainability/theme/theme3/recycle.html)
- **課題→施策→作用の転用仮説**：需要のばらつきと短い販売可能時間で期限切れが出る → 販売順序の誘導／安全性を保った販売期間延長／需要に応じた発注を組み合わせる → 販売機会を確保し期限切れ在庫を減らす可能性。
- **成立条件**：食品安全・品質、顧客の消費タイミング、物流温度、発注と棚陳列の実行。値引き・廃棄・欠品のトレードオフを同時に見る。
- **評価KPIと費用／仮説**：廃棄数量/金額、販売可能時間、欠品率、値引率、粗利、品質苦情。製造設備・検証・配送・包材の増分費用を含める。
- **例外・リスク**：販売期間が延びても発注量が増えれば廃棄が減らない可能性。期限・安全に関する事実は都度の公式確認を要し、思いつきで延長を勧めない。

### KNOW-MEASURE-004：顧客の受取制約を緩め、再作業を減らす

- **事例事実／採用済みB**：ヤマト運輸は2024-6から対象会員の宅急便等に置き配を追加し、受取場所選択と写真通知を提供した。[開始時の公式発表](https://www.yamato-hd.co.jp/news/2024/newsrelease_20240408_1.html)。統合レポート2025は、置き配指定増と連動して2025年3月期の**不在率8.8%**と報告している。これは企業の関連づけで、施策単独の因果効果や公的調査の再配達率と同一ではない。[公式レポートp.43–44](https://www.yamato-hd.co.jp/investors/library/annualreport/pdf/j_ir2025_06.pdf)
- **課題→施策→作用の転用仮説**：配達時刻と受取可能時刻が合わず再訪が発生 → 通知・時間/場所選択・安全な非対面受取 → 初回完了の確率が上がる → 再訪工数を削減する可能性。
- **成立条件**：荷物適合性、利用者の同意、置き場所・建物アクセス、安全・補償・通知、配送員の運用。対象外や契約条件は当時の発表に記載されるため現行サービス条件は再確認する。
- **評価KPIと費用／仮説**：初回完了率、不在率/再配達率の分母と定義、再訪時間・走行距離、盗難/破損・問い合わせ、顧客満足。通知/機器/補償の費用も比較する。
- **例外・リスク**：高価品・温度管理・受領確認、盗難・雨・誤配、建物アクセス。顧客選択に伴う層の違いや他施策・季節の影響がある。8.8%を他社の目標や改善幅へそのまま使わない。
