## 分類

資料が生じたら、解法methods/、前提知識facts/、施策・企業事例measures/へ保存する。内容のないファイルを大量に作らない。共通知識はモード別に全文複製せず、適用範囲case/fermi/sharedと参照先を持たせる。

## 記録項目

- 共通：ID、分類、要点、適用モードと条件、出典URL/資料・該当箇所、確認日、事実/見解/仮定の区分、採用/候補/失効の状態。
- 前提知識：値・単位・地域・対象年/期間・定義・概数化した場合の丸め方。統計の実数と面接で置く仮定を区別する。
- 解法：何を解く方法か、成立条件・限界、根拠、関連演習と改善記録。
- 施策例：課題、施策、企業が述べる狙い、観測された成果、残る課題、他の状況へ使う留保。実例とCodexの仮説を区別する。

## 信頼性と現行性

公的統計、政府・国際機関、企業公式資料等、主張を本文で確認できる信頼性の高い情報を優先する。解法・問題は発信者・前提・評価方法を確認し、1つの解説を唯一の正解としない。企業の自己評価と独立した検証を区別する。

収集時に必要な最新性を確認する。古い情報・定義違い・未確認を現行事実として扱わず、更新時は旧版と新出典を結ぶ。重要な知識だけNotionへ要約する。

共通知識にも情報ID・A/B/Cと理由・状態を付け、各領域INDEXから1つの本文へ参照する。[DOCUMENTATION](../../DOCUMENTATION.md)に従う。
