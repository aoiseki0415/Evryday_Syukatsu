# 問題集・解答・解説の台帳

状態：本人指定によりCaseMatchのAIチャットとケース面接ジムを①の同等の主要演習先として採用。ケース文字類題1問・フェルミの自己比較1問を試行。CaseMatch内記事の初期確認に着手し、網羅的inputと継続演習はこれから行う。

| source_id | 教材と所在 | 対象 | 利用・評価の状態 |
| --- | --- | --- | --- |
| CM-001 | [CaseMatch：操作・利用範囲](CASEMATCH.md) | 文字：ケース①・フェルミ①の主要演習先。音声：②の実践候補 | 文字の出題・講評・参考解答・修正・再評価を活用。ケース1問で一周確認済み。音声AI面接は①では使わない |
| GYM-001 | [ケース面接ジム：操作・禁止導線](CASE_INTERVIEW_GYM.md) | ①の主要演習先、CM-001と同等。今回はフェルミを検証 | 解答例を後から読み、差分をCodexが自己評価。問題→解答例→自己比較を1問確認。プロ相談は選択禁止 |
| CM-ART | [CaseMatch内記事の台帳](CASEMATCH_ARTICLES.md) | ケース①・フェルミ①の初期input | 評価観点本文、ケース分類の冒頭・見出しを確認。数字・例題記事の参照経路も記録 |

演習先の「同等の主要先」という重みは、情報項目のA/B/Cや問題ごとの正誤評価と区別する。本人の方針に従い両者の解答・講評を学習の基準として使い、同一AIを理由にCaseMatchを補助候補へ据え置いたり、外部の承認・採点を学習開始条件にしたりしない。計算・単位・定義の矛盾は通常どおり確認・修正する。

教材ごとにsource_id、名称・版、所在と参照方法、提供/確認日、対象モード、問題IDと分類、問題・解答・解説・採点基準の有無、評価に使える範囲、学習用/未見評価用の扱い、利用・公開範囲を記録する。

原資料は許可された元の場所に保持し、公開GitHubには認証情報・非公開の問題本文・解説全文を複製しない。所在と問題番号、自分たちの回答・照合・改善の要点を参照で結ぶ。利用できない資料・読めない問題・評価根拠がない箇所は未確認と記す。

両モードから同じ教材を使う場合、台帳は1件にして各INPUTから参照する。教材の解答に先に触れた問題と、未見評価に使える問題を区別する。
