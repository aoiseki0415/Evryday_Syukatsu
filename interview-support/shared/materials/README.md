## 初期inputの出典台帳

個別URL・資料ID・実際に読んだ範囲・出典の主張は、次の3台帳ノートを正本とする。同じURLをここへ全文複製せず、各INPUTからも参照する。

- [ケース初期input](../../modes/case/solve/input/2026-11-25-initial-methods.md)：CASE-WEB系列・CM-ARTの再読範囲。公式のサンプル解答を既読にした問題は未見評価に使わない。
- [フェルミ初期input](../../modes/fermi/solve/input/2026-11-25-initial-methods.md)：FERMI資料IDと読解/比較、未取得の範囲。
- [共通概数・施策事例](../knowledge/input/2026-11-25-facts-measures.md)：公的統計・企業一次資料の原表・発表時点。

Xは検索を試したが、今回の初期調査では解法採用の根拠にできる元投稿本文を確保していない。検索抜粋やAIによる投稿要約を確認済み解法へ登録しない。有料情報の購入・相談申込は行っていない。

演習先の「同等の主要先」という重みは、情報項目のA/B/Cや問題ごとの正誤評価と区別する。本人の方針に従い両者の解答・講評を学習の基準として使い、同一AIを理由にCaseMatchを補助候補へ据え置いたり、外部の承認・採点を学習開始条件にしたりしない。計算・単位・定義の矛盾は通常どおり確認・修正する。

教材ごとにsource_id、名称・版、所在と参照方法、提供/確認日、対象モード、問題IDと分類、問題・解答・解説・採点基準の有無、評価に使える範囲、学習用/未見評価用の扱い、利用・公開範囲を記録する。

原資料は許可された元の場所に保持し、公開GitHubには認証情報・非公開の問題本文・解説全文を複製しない。所在と問題番号、自分たちの回答・照合・改善の要点を参照で結ぶ。利用できない資料・読めない問題・評価根拠がない箇所は未確認と記す。

両モードから同じ教材を使う場合、台帳は1件にして各INPUTから参照する。教材の解答に先に触れた問題と、未見評価に使える問題を区別する。
