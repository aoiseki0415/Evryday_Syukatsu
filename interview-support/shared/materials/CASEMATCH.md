# CM-001：CaseMatchの利用経路と確認状況

確認日：2026-11-25。教材候補・操作情報。解法・概数の採用済み知識や、①の精度評価ではない。経緯は[操作ログ](../../logs/2026-11-25-research-and-casematch.md)。

## 現行の利用方針

本人の後続指示により、採点付きAI面接のCodex単独実行の検証は現段階で中断し、①の学習・評価には使用しない。①が十分な精度になった後の②で、本人がCaseMatchの問題に取り組みながらCodexの支援を受け、提示方法・途中依頼への適応を検証する場として使う。その過程で①の解法・知識にも課題が見つかれば、根拠とともに①へ戻して修正・更新する。②の支援品質と①の回答品質の評価は分ける。

通常の文字チャットは操作確認のみ。①の学習・採点を代替する手段として採用したわけではない。AI面接の実行や接続障害の追加調査を自動再開しない。

## 利用経路

- [ホーム・AIチャット](https://casematch.jp/chat/)：既存アカウントでログイン済み。通常のセッションを維持する。アカウントの識別情報・認証情報はここに記載しない。
- [企業別練習](https://casematch.jp/company/) → 企業 → 問題。サイト上の「公認」と、企業公式の過去問であることは分けて確認する。
- [面接練習](https://casematch.jp/competition/) → 問題詳細 → 面接を開始する → 注意事項 → 次に進む → 機器チェック → 面接開始、という導線。
- 問題詳細の「ランキング」からスコアと「回答を見る」の入口に到達できる。高得点回答を先に読んだ問題は未見評価用にしない。

## 確認できた範囲

| 機能 | 結果 | 限界 |
| --- | --- | --- |
| ログイン | 成功、ホーム遷移・アカウント表示を確認 | 有効期限は未確認。再ログインはOPERATIONSに従う |
| 問題一覧・詳細・ランキング | 操作可能 | 他人の回答全文・フィードバック詳細は今回未読 |
| 採点付きAI面接 | 機器チェックまで到達 | 面接ルーム接続エラー。開始・回答送信・採点未実施 |
| 機器チェック | オーディオ・マイク・カメラの確認を要求。開始ボタン無効 | マイク・カメラの選択肢に実機が表示されない。接続エラーとの因果は未特定 |
| オーディオの再生ボタン | 反応し「聞こえた／聞こえない」が表示 | Codexが実際に聞こえたと確認できないため、聞こえたとは申告していない |
| 文字チャット | 操作テストの仮回答を送信し、計算・仮定への文章フィードバックを受信 | 点数は出ない。採点付き面接の完走や精度評価と別 |

サイト内AIは「文字だけで点数を得る機能はなく、採点は音声セッション」と案内した。これはAIの案内として記録し、サービス全機能の網羅的な仕様保証とは扱わない。今回の機器チェック画面には文字回答への切替は見当たらなかった。音声回答が公開される場合があるという注意も表示されたため、回答には本人の個人情報を含めない。

## 検証した問題と扱い

[タクシー業界の市場規模推定](https://casematch.jp/competition/838b70d1-3216-49bb-8c33-fc9cc03d7c74/)を操作検証に使用。詳細の解法ヒント・ランキング表示を閲覧済み。今後、完全な未見問題とは扱わない。

文字チャットへ送った独自の仮回答は、20万台×20乗車/台日×2,000円/乗車×300日/年＝2.4兆円/年。値はすべて検証前のラフな仮定で、採用済みの前提知識へ登録しない。フィードバックは計算の整合性、車両数と稼働日数の定義の統一、乗車回数と平均運賃の根拠の必要性。本格学習の成果・①の精度向上・本人の実力評価には計上しない。

## 接続の制約と再開

Codex内ブラウザで面接ルーム接続に失敗し、再読み込み後も再現した。ネットワーク表示は「良好」でもルームには接続できなかった。原因は未特定。VPN・ネットワーク設定・セキュリティを変更していない。Chrome/Edgeによる同環境での検証、マイク・カメラを認識した状態、合成音声を通常の入力として送る手段、面接官音声をCodexが取得する手段はいずれも未検証。

接続障害の解決・Codex単独の音声送受信の検証は中断。②で本人が操作・回答する利用へ切り替える方針で、実際の②の演習はまだ開始しない。単に画面操作できることと、自律的に音声面接を完走できることを混同しない。課金せず、非公開の問題・他人の回答全文・アカウント情報を公開GitHubへ複製しない。
