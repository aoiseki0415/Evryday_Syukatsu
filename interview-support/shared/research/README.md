# 必要時に素早く調べる探索経路

状態：速報・企業情報等へ素早く到達する経路の体系化と速度検証は今後行う。①の解法・演習資料の探索は着手し、[教材・資料台帳](../materials/README.md)とCaseMatch内記事の経路に保存した。確認済みの入口と、未確認のテーマ別経路を混同しない。

## 目的

[確認済みのテーマ別経路](PATHS.md)を登録。一次資料の入口/本文までの到達範囲、未読の値、速度未計測を区別する。

事前知識のinputに加え、対話中に必要になった情報へ素早く到達し、本人へ共有する「パス」を作る。日本政治・国際情勢・環境問題の実情と、企業の認識・対応・成果・課題等を扱えるようにする。

## 後で整備する項目

テーマ/質問、最初に見る一次情報、検索語、確認項目、更新頻度・時点、代替経路、短く共有する形式、最後に経路を確認した日・結果。統計、制度・政策、国際情勢、環境、企業動向等の区分は収集時に具体化する。

## 情報が必要になったときの共通方針

1. 知る必要のあること、地域・時点・定義を絞る。
2. 経路から一次情報・信頼できる情報を探し、本文を確認する。
3. 実情・事実、企業の認識、対応、成果、課題、Codexの推測を分ける。未開示は未開示とする。
4. 要点、出典、時点、未確認点を短く共有する。調べる約束だけで確認済みのように答えない。
5. その場の結果はsession、再利用する情報はknowledge、再利用する探索経路はここへ残す。

速さのために古い情報を無条件に再利用したり、別事例を1つの成果に合成しない。具体的なテーマ別手順と速度目標は今後検討する。
