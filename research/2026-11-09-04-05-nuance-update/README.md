## 確定した整理

1. 全社レベルのAI導入支援の重要性が現在指摘され、実際の支援事例・各社の提供体制にもその方向性が現れている。市場全体の案件比率が全社へ移行したとは断定しない。
2. 理由は、業務・組織が相互依存し、個々の業務をAIで効率化するだけでは企業全体の価値・成果を十分に引き出せないことがあるから。
3. 全社の成果を目指すと、AI活用を前提とした人材配置・組織構造、部門間の業務、投資・経営方針、基盤・統制など、追加的に考慮・設計することが増える。項目の数に加え、領域間の整合と部門横断の判断が難しい論点になる。
4. それを支援するには、AI技術に加えて、顧客目的に必要な複数領域の専門性を結び付けることが重要。企業・チームの協働、必要に応じた外部専門家との協働を含む。
5. 05では本人の全社インパクト志向を重ね、幅広い専門性を備えて協働でき、本人もその知見を学べる環境を理想①とする。一人に全分野の専門家になることを求めず、AIを軸に関連領域の理解を深める。

04は支援上の必要性、05は本人の志向と重ねた環境条件。ガバナンスは複数領域の一つ・補足であり、独立第三条件にしない。全社すべてへの一斉導入・全領域再設計も要求しない。
