# AIの技術的理解と、事業・全社戦略への関与を両立する志向

日付：2026年11月5日。本人は前回52候補の調査後、「まず理解と議論」を依頼。今回は添付3図、デロイト評価の過去ログ、指定したDI・IGPIの公式説明を確認し、志向と調査漏れを整理した。新しい全社・全職種の網羅調査、シート再編集は未実施。

## 本人が伝えたこと

- AIを知っている・ツールを使える段階を超え、技術の仕組みと限界まで理解したい。デロイトの技術的な厚みを高く評価した過去の見方は継続。
- 個別業務のAI導入だけに閉じず、AIによって企業の競争優位、事業、収益構造、組織や今後の経営方針をどう変えるかに関わりたい。
- 技術と戦略が中程度ずつという意味のバランスではなく、**技術理解の深さと戦略への関与の両方**を満たす環境を探す。
- 会社に戦略とAIの機能があるだけでは不足。本人がAI・データの専門作業だけを担当して戦略の議論から離れる配置は好ましくない。戦略担当者・技術担当者が協働し、自分も両方の議論へ関われることが重要。
- DI、IGPIの提示サービスには好印象。ただし志望順位・応募の決定ではない。BCGに対する役割分離の懸念は印象として持っている。

## 今回明示的に更新された調査条件

- **日本の募集入口が必須**。従来の28卒・大学院生・新卒の条件を併せ、日本の該当する応募入口を確認できるものを候補とする。海外だけに存在する専門職は現行候補へ入れない。国内の入口不明と、国内に入口があって確認回が終了した場合を区別する。今回「本日受付中」までを一括必須とする発言はない。
- **AI側の探索ではSIerを外す**。別のITアーキテクトルートを取りやめる決定とは扱わない。
- 総合コンサルは**Big4とAccentureの5先で十分**とした。その他を無制限に増やさず、戦略・経営変革寄りの企業・部署・役割へ探索の力点を移す。
- 企業ラインの従来の「Accenture以上」、自社製品に縛られない選択、DS任意という条件は撤回されていない。添付の企業図だけで、以前の対象外企業を自動で候補へ戻さない。
- 旧52候補は前の4分類・募集未確認も残す条件での調査履歴。今の条件を満たす候補としてそのまま再利用しない。今回はシートを変更していない。

## 志向の言語化案（Codex提案、本人の最終表現は未確定）

> AIの技術的な可能性と限界を深く理解し、その理解を使って、企業がどこで価値を生み、何に投資し、事業や組織をどう変えるかを構想したい。戦略と技術の両方の議論に参加し、実現まで関わりたい。

検討用の表現は「AIを前提に企業・事業を再設計する仕事」「技術に根差したAI戦略・事業変革」。正式な募集職種名ではない。AIアーキテクトという到達先の呼び方を最終決定したわけでもない。

本人の「3〜5年後にはAI導入だけの仕事が淘汰されるのでは」は将来仮説。全企業の導入が完了することや、上流職なら将来安全であることを確定事実にしない。技術の進展に応じた更新・統合・運用にも価値が残る可能性があり、志向は特定の淘汰予測に依存せず表現できる。

会社の上流／下流の重心は初期の地図として使えるが、技術深度を一本の軸で代用しない。今後は①AIの技術的理解、②扱う戦略の範囲、③本人が両方へ関わる実態、を別に確認する。
