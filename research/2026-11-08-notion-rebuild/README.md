## 先にそろえた呼称

- **AI変革支援**：顧客企業がAIを活用して事業・業務・組織等を変えることを、構想・設計から導入・実行、定着・運用・改善まで支援する仕事。AIを使う主体は顧客企業。
- **AI・データ**：支援領域。
- **AIアーキテクト**：本人が目指す役割・到達像。正式な新卒職種名と同一とは限らない。
- **今後求められるAI変革支援**：重要性が増すと見込まれる支援についての外部見解と統合要約。現在から必要な提言を含み、確定した未来ではない。

そのほかの類似表現は[glossary.md](glossary.md)に統一。公式の法人・部門・職種名や原文の表記は保存する。

## 05で統合したもの

目指す支援像は、**AIの技術的な可能性と限界を踏まえ、顧客企業の価値創出と組織運営を構想し、実装・運用の知見を使って実現・更新する支援**と整理した。

| 条件 | 観点 | 位置付け |
| --- | --- | --- |
| C1 | 価値・全社の変革 | 本人の志向からの中核 |
| C2 | 技術への実質的関与 | 本人の志向からの中核 |
| C3 | 構想と実装の接続 | 本人の関与可能性を間接評価する中核 |
| C4 | 人・組織を含む設計 | 将来像への適合を深める加点観点 |
| C5 | 統制と継続的な変革 | 将来像への適合を深める加点観点 |

**C4・C5は新たな絶対条件ではない。** 単独の未確認だけで候補を除外せず、本人が一人で人材改革や統制を専業として担うことも求めない。会社・チームの協働する環境を見る。条件の内容、根拠として何を見るか、本人が担当できるかは別々に整理する。詳細は[05-criteria.md](05-criteria.md)。

## 06の候補と調査範囲

[candidates.json](candidates.json)には、**23候補環境・17企業グループ**を収録した。内訳は次の通り。

| Codexの抽出区分 | 環境数 | 意味 |
| --- | ---: | --- |
| 優先して比較 | 14 | 中核条件への具体的な根拠があり、将来像にも整合する |
| 条件付きで残す | 5 | 環境は近いが、役割・対象範囲・国内経路等に重要な確認が残る |
| 追加確認・保留 | 4 | 関連性はあるが、中核条件の裏付けが足りない |

企業×部門・専門組織×職務・役割を候補環境の単位とする。同じ企業でも役割が違えば別行。比較IDは18種類あるが、KPMGコンサルティングとKPMG FASを企業グループとして一つに数えるため17グループとなる。これはIDCによる17社の評価や、本人が選んだ17社という意味ではない。

今回の公式再照合は、**総合5社（Big4＋Accenture）と既存の戦略・経営変革系、および周辺の追加候補**を中心に実施した。旧45社台帳・61探索ラベルも候補漏れの確認に参照したが、**全45社・全61ラベルの公式情報を今回すべて最新に再調査したものではない。** 今回の候補外を、AI能力がない企業と断定しない。

制約は、本人と合意した企業ライン、総合5社、AI側の純SIer除外、日本の大学・大学院新卒入口を継続。データサイエンスは加点。国内入口、28卒の現在受付、専門配属を別に記し、募集回の終了だけで仕事環境を削らない。能力・実績と本人の選定範囲を混同しない。

## 情報と判断の区別

| 層 | この記録での扱い |
| --- | --- |
| 確認事実 | 公式案件・組織説明・募集本文にある内容。PoC、本番、予定、継続運用を区別 |
| 外部の見解・評価 | 記事の提言、IDCの観察、顧客調査。将来の事実や本人の希望とは別 |
| Codexの統合判断 | C1〜C5の適合、抽出区分、推薦。根拠と未確認事項を付す |
| 本人の決定 | 既に合意した志向・制約と、今後本人が選ぶ志望・応募先。推薦だけで更新しない |

IDCは**世界のAIサービス組織**の現在能力と今後3〜5年の戦略を扱う。各社が公開する同一報告書の抜粋を独立調査と数えず、Leaders区分と個社の強み・課題を区別する。日本の希望部署・若手の担当・採用や配属の保証には使わない。詳しくは[idc-review.md](idc-review.md)。そこでの15社・対象6社・対象外9社は11/7の旧一覧に対する照合範囲で、拡張後の17グループを全件照合し直した結果ではない。

### 再生成スクリプトについて

`build_artifacts.py`と`verify_artifacts.py`は今回の移行・検証用。元のNotionスナップショットは私的な一時ファイルで、公開リポジトリに含めない。通常の引き継ぎでは保存済みの候補・出典・本文・検証記録を読む。再移行時は現行Notionを取得し直し、古い一時スナップショットの盲目的な再実行をしない。`build_comparison.py`は比較本文を生成し、書き込み時には現行の子ページタグを保持する。

個社のIDC追補は[idc-profile-additions.json](idc-profile-additions.json)。新しい根拠・募集と以前の記述を混ぜず、各社の旧本文は履歴トグルに保持した。
