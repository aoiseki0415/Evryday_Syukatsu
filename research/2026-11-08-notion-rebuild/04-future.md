<callout icon="🔭" color="orange_bg">
<b>今後求められるAI変革支援：顧客企業の価値創出と運営の仕組みを、AIの能力を踏まえて設計・実現・更新する支援。</b>

各社記事の共通点とIDCの観察からの統合要約。現在から必要な提言と将来シナリオを含み、需要の多数派や確定した未来を示すものではない。

## 1｜支援が広がる二つの方向

<columns>
<column ratio="50">
<callout icon="🔴" color="red_bg">
<b>価値創出・企業の仕組み</b>

顧客価値・競争戦略・事業モデル、業務、人材・組織、資源配分をつなぐ。
</callout>
</column>
<column ratio="50">
<callout icon="🟢" color="green_bg">
<b>AIへ任せて動かす仕組み</b>

判断・実行の権限、責任、人の関与、監視・是正を設計する。
</callout>
</column>
</columns>

本人が赤字・緑字で捉えた二つの観点。統制はAI活用を進められる条件でもある。全社化に加え、AIへ委ねる権限や判断の影響に応じて必要になる。

## 3｜IDCが示す、支援企業に必要な能力

<b>記事からは「どんな顧客変革を支援するか」、IDCからは「その支援を担う企業には何が必要か」を読む。</b>

| IDC共通本文・助言の観点 | 支援企業に求められること |
| --- | --- |
| 事業目的・顧客の成熟度 | 技術選択に先立って、目的・優先案件・成果を明確にする |
| 戦略・統制・人材と技術運営 | 経営の仕組みと、データ・アプリ・開発運用を結び付ける |
| 顧客内部・外部専門家との協働 | 事業とITを調整し、必要な専門性を組み合わせる |
| PoCから本番・展開へ | 開発・運用・人材育成までつなぎ、実験の成果を実用化する |
| 知見・資産・提携の活用 | 方法論・再利用資産と、顧客が選ぶ技術を組み合わせる |

出典：[IDC世界AIサービス2025・EY公開抜粋](https://www.ey.com/content/dam/ey-unified-site/ey-com/en-gl/about-us/analyst-relations/documents/ey-gl-idc-marketscape-worldwide-artificial-intelligence-services-2025-vendor-assessment-08-2025.pdf)、共通本文・買い手向け助言p.2–5。同じ報告書の各社抜粋を独立した複数調査には数えない。

<toggle heading="h3">
IDCの評価・顧客調査をどう読むか

- 現在の能力と、評価時点から今後3〜5年の顧客ニーズへの戦略適合を評価する。すべてが未来だけの論点ではない。
- 図2の顧客72件による重要度では、望む成果の達成が最重要。各社のスコアではない。
- 顧客内部チームとの統合は、提供会社の属性について満足度が全体で最も高かった項目。上記の重要度とは別の問い。
- Leaders区分、個社の強み・課題、本人の条件への適合判断を分ける。
- 対象外は低評価を意味しない。グローバル評価は日本の特定部署・新卒配属の評価ではない。
- 独自資産・提携の保有はIDCの対象条件にも関係する。本人の技術選択の自由度は別に確認する。
</toggle>

## 4｜4要素へ置き直す

| 要素 | 今後の支援像としての読み取り |
| --- | --- |
| <b>変革の対象範囲</b> | 業務の改善に加え、事業の価値提供と全社の運営・資源配分へつなぐ |
| <b>支援領域</b> | AI・データを起点に、戦略・業務・人材組織・統制を結ぶ |
| <b>支援工程</b> | ①企業像を構想→②人・AI・組織・システムを設計→③実現→④成果とリスクから更新 |
| <b>企業カテゴリー</b> | この支援はカテゴリーをまたぐ。以降は各社の案件・体制・役割で比較する |

①が扱う内容を具体化することと、③④への接続を保つことを同時に考える。全社共通ツールの配布だけで、競争戦略や組織まで変えたとは判断しない。

## 5｜相違点も残す

<toggle heading="h3">
共通点に加え、記事の焦点はどう違うか

| 観点 | 重点の違い |
| --- | --- |
| 競争優位 | BCG・Bainは独自データや知識の蓄積、EYは組織内外の摩擦を減らすつながり |
| 責任と実行 | BainはCEOの目的・成果責任、Kearneyは実行の専門家への委譲と技能移転 |
| 将来像と現在地 | PwC・EYは組織の将来像、MRI・ADLは現場の学びや技術の制約を踏まえる進め方 |

両立する観点を含み、企業の排他的な思想や能力順位とはしない。各社の詳細は記事ノートに残す。
</toggle>

<toggle heading="h3">
今回、結論にしていないこと

- 技術理解が不要になる、企業の実行力が均等になる、戦略だけが残るという結論。
- 全社変革が既に市場の案件の多数派であるという推計。
- 将来の組織像やAGIの時期が確定しているという予測。
- 記事の提言が、そのまま希望部署の実績や本人の担当を示すという判断。
</toggle>
