<callout icon="🎯" color="green_bg">
<b>目指す支援像：AIの技術的な可能性と限界を踏まえ、顧客企業の価値創出と組織運営を構想し、実装・運用の知見を使って実現・更新する支援。</b>

03の本人の志向と、04の今後の必要性を統合した整理。以下は企業・部門・職種の比較に使う枠組み。新たな個人の志望順位や配属保証とは分ける。
</callout>

<callout icon="↓" color="green_bg">
<b>構想する内容を、AI導入の計画から「AIを前提に企業がどう価値を生み、どう動くか」まで具体化する。</b>
</callout>

| 自分の志向 | 記事・IDCから読む必要性 | 統合すると、どんな支援を目指すか |
| --- | --- | --- |
| ①構想を軸にしたい | 技術選択の前に事業目的・価値を明確にする | <b>事業価値から企業の変革を構想する</b> |
| 全社へインパクトを与えたい | 業務・人材・組織を同時に設計する | <b>全社の価値創出と運営をつないで変える</b> |
| ③④から技術を理解したい | PoCから本番へ進める実行力が必要 | <b>技術の実力・制約を踏まえ、実現までつなぐ</b> |
| 構想と技術の両方に関わりたい | 顧客内部・外部専門家との接続が評価される | <b>戦略・業務・技術の協働の中で役割を持つ</b> |
| 導入後も意味のある支援をしたい | 統制・能力移転・継続改善が必要 | <b>顧客が安全に使い、変わり続けられる状態へつなぐ</b> |

左列は既存の志向・問題意識、中央列は外部の提言・評価、右列はその統合判断。中央列が確定した未来、右列が本人の最終ES文面という意味ではない。

C4・C5は将来像への適合を深める加点観点。単独の未確認だけで候補を除外せず、本人が新たに必須と決めた条件とはしない。一人で専業として担当することも求めない。会社・チームが必要な専門性を組み合わせ、目指す変革を支えられるかを見る。C1〜C5の情報不足は「未確認」とし、同じ意味の不適合に置き換えない。

## 3｜条件と、確認するすべを分ける

| 条件 | 主に見る情報 | 読み取る範囲 |
| --- | --- | --- |
| C1｜価値・全社 | 顧客案件・プレスリリース | 目的／対象／変えた内容／提供者の活動／進行状態 |
| C2｜技術 | 技術記事・実装事例・運用の説明 | 実際に行った判断・開発・改善。単なる提供範囲との違い |
| C3｜接続 | チーム構成・社員案件・新卒の仕事紹介 | ①と②〜④の協働。本人の担当は可能性として評価 |
| C4｜人・組織 | 組織・人材とAIの共同案件 | 導入に伴う役割・体制・行動の変化 |
| C5｜統制・更新 | 運用・ガバナンス・能力構築の実例 | 使い続けられる仕組みと改善・自走への移転 |

<toggle heading="h3">
IDCをどこへ使うか

- <b>条件を作る材料</b>：事業目的、統合的な支援、PoCから本番、顧客内部チームとの接続等、評価される能力を04で整理する。
- <b>個社比較の材料</b>：06で各社の強み・課題を補助証拠として使う。
- グループの世界評価だけで日本の部門や本人の職務を確定しない。
- IDCのLeaders区分、個社プロフィール、こちらのC1〜C5適合判断を別に表示する。
</toggle>

## 4｜入口・制約条件は別に確認する

| 観点 | 使い方 |
| --- | --- |
| 日本の新卒・大学院生向け入口 | 仕事の適合と別に、入社経路を確認する |
| 28卒対象・現在受付 | 本選考／インターン／プレ登録／終了／未確認を分ける |
| 専門配属 | 確約・希望考慮・一般採用を分ける |
| 技術選択の自由 | 顧客に応じた複数技術の選択と、特定製品・提携の制約を確認する |
| データサイエンスとの接点 | 本人の研究・分析経験を生かす加点要素 |
| 企業の対象ライン | 03の合意済み条件を継続する |

## 5｜06での抽出方法

<b>C1〜C3の実案件・体制の根拠 → C4・C5を含む将来像への適合 → 国内入口と確認事項</b>の順に見る。

| 表示 | 意味 |
| --- | --- |
| <b>優先して比較する環境</b> | 中核条件の具体的な根拠があり、将来像にも整合する |
| <b>条件付きで残す環境</b> | 環境は近いが、役割・対象範囲・国内経路等に重要な確認が残る |
| <b>追加確認・保留</b> | 関連性はあるが、現時点の公開情報では中核条件を十分に確かめられない |

募集回の終了だけで仕事環境を消さない。抽出はCodexの推薦であり、本人の最終的な志望・応募決定は06で区別する。
