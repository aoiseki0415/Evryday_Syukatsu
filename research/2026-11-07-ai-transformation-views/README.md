# AIに関わる顧客企業の変革を、どう支援するか

調査日：2026年11月7日。対象はNotion「理想の企業像を満たす環境一覧」の主12社と有力保留3社、計15社グループ。順位・募集・候補の追加変更は行っていない。

## 確定した調査の問い

**顧客企業が今後AIを使って事業・経営・業務等を変革するとき、コンサル側はその変革をどう構想・設計し、どの方向で支援するべきか。**

- AIの進化・普及で顧客の課題と支援がどう変わるかも、この問いに含める。
- コンサル自身の作業へのAI利用は中心対象ではない。混在する記事は顧客支援に関係する箇所だけを使う。
- Deloitteの共有記事は方向性の参照例。企業間の重み付けはしない。
- 以下は**各記事の提言を比較した要約**。全社の総意、実証済み法則、企業の実装能力や本人の配属の証明ではない。

## 1. 共通点：複数社の記事に繰り返し現れる支援原則

全15社が全項目へ同じ強さで賛同した、という意味ではない。

| 共通する考え | 顧客の変革で扱うこと | 支援内容としての読み取り | 代表的な根拠 |
| --- | --- | --- | --- |

**統合した要約（Codexの解釈）**：AI導入後にも必要になる支援は、顧客企業の「価値を生む仕組み」を、人・AI・業務・組織・データ・統制をつないで設計し、実践から更新し続けられる状態にすること。

これは「技術を理解しなくてよくなる」「実行力は全企業で均等になる」「戦略だけが残る」という結論ではない。技術・データ・組織の準備と、判断・実行のつなぎ方に差が残るという記事が多い。

## 2. 相違点：記事がどこへ焦点を当てているか

各社の能力を独占的に分類・順位付けした表ではない。発信者・法人・国・記事の文脈による違いを残す。15社の具体例、役職、原文リンクは[企業別ノート](companies/)と[sources.json](sources.json)。

| 企業 | 選んだ記事に見える焦点 |
| --- | --- |
| Deloitte | AIの能力と、人材ポートフォリオ・損益の接続 |
| PwC | 個人の能力増幅から組織形・CAIOの役割への転換 |
| EY | 組織内外の調整を減らすネットワークと人の責任 |
| KPMG | AIを使う経営判断と、変化に追いつく統制 |
| Accenture | 仕事・スキル・学習を更新し続ける企業能力 |
| BCG | 利益の移動、競争優位、戦略とAI能力の接続 |
| McKinsey | 成果を持つ共同チーム、基盤、自走する企業能力 |
| Bain | CEOの成果責任、業務と人材、独自の学習資産 |
| DI | 新事業・R&D・収益化と経営の接続 |
| Globe-ing | 顧客固有の暗黙知と、現場の業務成果 |
| NRI | 人の役割変化、資源配分、深さと横展開の設計 |
| MRI | 全社設計と現場の往復、余力の成長への再配分 |
| Kearney | 将来像と実行の分担、段階的な価値検証と技能移転 |
| ADL | 技術の実力と制約に即した変革順序、R&D・開発組織 |
| IGPI／IGPI DI | AIで既存事業を変える深化と、次の収益の探索の循環 |

### 違いを消さずに読む三つの点

- **経営の責任と分権**：BainはCEOの目的・成果責任、Kearneyは日々の実行を専門家へ委ねることを強調。責任と細部の管理は別なので、対立と決め付けない。
- **独自性と接続性**：BCGやBainは独自データ・知識、EYは摩擦の少ないエコシステムを前面に出す。内部の競争資産と外部接続をどう両立するか、という視点の違い。
- **目指す姿と進め方**：EY・PwCは遠い組織像、MRI・ADL・Kearneyは現在地から学んで広げる進め方を詳述。将来像を描くことと段階導入は両立する。

## 3. 読み方と取得範囲

- [調査過程・対象範囲](PROCESS.md)
- [50 URLの台帳](sources.json)：44資料の本文を確認。中心資料38、補助6。残る6はハブ・探索用・本文未取得等として除外。
- PwCの紹介記事と31頁報告書は同一系列。独立した二件の証拠に数えない。38中心資料は、この二形式を含むURL単位の数。
- 本文を要約に使う資料は結論まで確認。PDFはPwC31頁、Accenture34頁、NRI4頁、Kearney38頁、IGPI8頁の全頁テキストを確認。図中文字・注記も確認したが、すべての図版ピクセルを目視したという記録ではない。
- リンク先の全資料・全動画まで精読したとはしない。Bainの七章ガイドは導入本文を一資料として扱い、未読の各別章は根拠に含めない。
- 公開日・役職は掲載時の表記を基本とする。日付・個人著者が明示されない資料は補完しない。海外の思想を日本の部門実績・新卒配属へ転用しない。
- 事例は「各社が掲載した報告」。匿名例・仮想例・自社実践・提言を区別し、外部原報や成果値を今回独立検証したとはしない。
